# 各学科优质教案范例

## 教案范例一：数学——二次函数 y = ax² 的图像与性质

### 一、基本信息

| 项目 | 内容 |
|-----|------|
| 学科 | 初中数学（九年级） |
| 课题 | 二次函数 y = ax² 的图像与性质 |
| 课时 | 1 课时（45 分钟） |
| 教材 | 人教版九年级数学上册第二十二章第一节 |
| 授课教师 | — |

### 二、教学目标

#### 知识与技能
1. 学生能用描点法准确画出 y = ax² 的图像
2. 学生能从图像中归纳出抛物线 y = ax² 的开口方向、对称轴、顶点坐标
3. 学生能理解参数 a 对图像形状和位置的影响

#### 过程与方法
1. 经历"画图—观察—猜想—归纳—验证"的研究函数的一般过程
2. 通过对比 y = x²、y = 2x²、y = -x² 的图像，掌握数形结合的思想方法

#### 情感态度与价值观
1. 通过动手画图和自主探究，培养学生严谨细致的学习习惯
2. 感受数学图像的对称美，激发学习数学的兴趣

### 三、教学重难点

| 项目 | 内容 |
|-----|------|
| 教学重点 | y = ax² 的图像特征与基本性质 |
| 教学难点 | 参数 a 对抛物线开口宽窄和方向的影响 |
| 突破方法 | 几何画板动态演示 + 学生分组对比画图 |

### 四、教学准备

| 教具/学具 | 用途 |
|----------|------|
| 几何画板课件 | 动态展示参数 a 变化时图像的变化 |
| 方格纸（每人一张） | 学生描点画图 |
| 彩色笔（红、蓝） | 分别画 a>0 和 a<0 的图像 |
| 对比分析表格（每组一份） | 记录观察结果、归纳性质 |

### 五、教学过程

#### （一）情境导入（5 分钟）

**情境**：同学们在游乐场都玩过投篮吧？篮球出手后在空中划过一条优美的曲线——这就是我们今天要研究的"抛物线"。喷泉的水流、卫星天线的截面，都和抛物线有关。今天，我们就从最简单的二次函数 y = ax² 开始，来研究它的图像和性质。

**提问 1**：我们之前学过一次函数 y = kx + b，它的图像是什么？（直线）
**提问 2**：研究函数图像的一般步骤是什么？（列表、描点、连线）

**设计意图**：用生活情境激发兴趣，同时回顾已有知识，为新课做铺垫。

#### （二）新知探究（20 分钟）

**探究活动 1：全体学生画 y = x² 的图像（10 分钟）**

步骤：
1. 列表（学生独立完成 x 从 -3 到 3 整数值）：
   | x | -3 | -2 | -1 | 0 | 1 | 2 | 3 |
   |---|----|----|----|---|---|---|---|
   | y | 9 | 4 | 1 | 0 | 1 | 4 | 9 |

2. 描点（提醒学生坐标要准确，点要清晰）
3. 连线（用平滑曲线从左到右连接）

教师巡视，选取 1-2 份学生作品在投影上展示，点评优缺点。

**探究活动 2：分组对比画图 + 几何画板演示（10 分钟）**

全班分 4 组，每组再分两小队：
- 1 组：y = 2x²  vs  y = x²
- 2 组：y = ½x²  vs  y = x²
- 3 组：y = -x²   vs  y = x²
- 4 组：y = -2x²  vs  y = x²

各组完成对比表格：

| 函数 | 开口方向 | 对称轴 | 顶点 | a>0 / a<0 | a 的绝对值越大，开口越 ___（宽/窄） |
|-----|---------|-------|------|----------|----------------------------------|
| y = x² | | | | | |
| y = 2x² | | | | | |
| y = -x² | | | | | |

教师用几何画板拖动参数 a，让学生观察：
- a > 0 时，开口向 ___ 上，顶点最 ___ 低
- a < 0 时，开口向 ___ 下，顶点最 ___ 高
- |a| 越大，开口越 ___ 窄

**设计意图**：通过"动手做 + 对比看 + 动态演"三重手段突破难点。

#### （三）性质归纳（8 分钟）

在各组汇报基础上，师生共同总结：

**二次函数 y = ax² 的图像是一条抛物线，性质如下：**

| 性质 | a > 0 | a < 0 |
|-----|-------|-------|
| 开口方向 | 向上 | 向下 |
| 对称轴 | y 轴（x = 0） | y 轴（x = 0） |
| 顶点坐标 | (0, 0) | (0, 0) |
| 增减性 | x < 0 时，y 随 x 增大而减小；x > 0 时，y 随 x 增大而增大 | x < 0 时，y 随 x 增大而增大；x > 0 时，y 随 x 增大而减小 |
| 最值 | x = 0 时，y 有最小值 0 | x = 0 时，y 有最大值 0 |
| 开口宽窄 | |a| 越大，开口越窄 |

**快速练习**：
1. y = 3x²：开口方向 ___，对称轴 ___，顶点 ___
2. y = -0.5x²：开口方向 ___，当 x ___ 时 y 随 x 增大而增大

#### （四）巩固提升（8 分钟）

**例题 1**：已知抛物线 y = ax² 经过点 (2, 8)，求 a 的值，指出开口方向和对称轴。

**例题 2**：函数 y = -2x² 上有两个点 A(x₁, y₁)、B(x₂, y₂)，若 x₁ < x₂ < 0，比较 y₁ 和 y₂ 的大小。

**例题 3（拓展）**：一个涵洞的截面是抛物线形，以涵洞顶点为原点，建立坐标系。若涵洞宽 4 m 时，高 2 m。求这条抛物线的解析式。

#### （五）课堂小结（3 分钟）

师生共同用思维导图回顾：
```
y = ax²
├── 图像：抛物线
├── 画法：列表 → 描点 → 连线
└── 性质
    ├── 开口方向：a>0 向上，a<0 向下
    ├── 对称轴：y 轴
    ├── 顶点：(0, 0)
    └── 开口宽窄：|a| 越大越窄
```

#### （六）布置作业（1 分钟）

A 层（必做）：课本习题 22.1 第 1、2、3 题
B 层（选做）：思考——如果函数变成 y = x² + 1，图像会发生什么变化？试着画图猜一猜，下节课分享。

### 六、板书设计

```
┌──────────────────────────────────────┐
│        二次函数 y = ax² 的图像与性质          │
├──────────────┬───────────────────────┤
│              │                       │
│  画图步骤    │    性质总结表           │
│  列表        │    （对比 a>0 和 a<0）  │
│  描点        │                       │
│  连线        │                       │
│              │                       │
├──────────────┤                       │
│              │                       │
│  学生作图区  │    例题解答区           │
│  （实物投影） │                       │
│              │                       │
└──────────────┴───────────────────────┘
```

### 七、课后反思

1. **画图时间是否充裕**？学生画函数图像时，部分学生描点位置不够准确，需要在今后加强训练。下次课可以提前印好坐标系，节省时间。
2. **几何画板演示效果**：学生反映动画演示非常直观，参数 a 拖动时图像连续变化的效果让他们对"|a|越大开口越窄"理解得很清楚。这一环节保留并加强。
3. **B 层选做题的铺垫**：y = x² + 1 是下节课的内容，部分学生已经猜测到"整体向上平移 1 个单位"，说明学生迁移能力较强。下节课可以直接从学生的猜想引入。
4. **分层教学**：B 层选做题中，有 60% 的学生尝试了画图，可以设计更丰富的拓展任务供优秀学生挑战。

## 教案范例二：语文——议论文写作指导（事实论据的选择与使用）

### 一、基本信息

| 项目 | 内容 |
|-----|------|
| 学科 | 高中语文（高二） |
| 课题 | 事实论据的选择与使用——让议论文有理有据 |
| 课时 | 1 课时（45 分钟） |
| 教材 | 人教版高中语文必修三 表达交流单元 |

### 二、教学目标

1. **记忆**：学生能说出选择事实论据的三条原则（真实、典型、新颖）
2. **理解**：学生能辨别论据使用中的常见问题（论据与论点不吻合、以叙代议、堆砌论据）
3. **应用**：学生能围绕给定论点选择恰当的事实论据，并写一段分析说理的话
4. **分析**：学生能分析一篇议论文范文中论据与论点的关系
5. **评价**：学生能评价同学作文中论据使用的优劣并提出修改建议
6. **创造**：学生能为"坚持就是胜利"这一论点自拟一个事实论据片段

### 三、教学重难点

**重点**：事实论据选择的三原则；论点 + 论据 + 分析的三层结构
**难点**："论据之后的分析"——如何避免以叙代议，让论据真正支撑论点

### 四、教学过程（核心环节）

#### 导入：病例诊断（5 分钟）

投影展示一段病文，让学生找问题：

> **论点："坚持就是胜利"**
> 德国医学家欧立希为了发明一种新药，坚持进行试验，失败了，总结教训再干。他一直试验了 606 次，才获得了成功，制出了以试验次数命名的新药 606。**由此可见，坚持就是胜利。**

**提问**：这段话有没有问题？最大的问题在哪里？

→ 学生讨论后明确：只有"论点 + 论据"，缺少**分析**。"为什么坚持就胜利了？欧立希的坚持体现在哪些方面？"这些都没有讲，论据和论点之间像隔着一条河。这就是最常见的**"油水分离"**——以叙代议，例而不议。

#### 核心方法："观点 + 论据 + 分析"三层结构（20 分钟）

**分析句的几种写法**：

**写法一：因果分析**（为什么？因为……）
> ……制出了新药 606。**为什么欧立希能取得成功？正是因为他面对失败毫不气馁，一次又一次地坚持，才最终等到了第 606 次的成功。** 可见，坚持是通往胜利的必经之路。

**写法二：假设分析**（假如不……？那么……）
> ……制出了新药 606。**假如欧立希在第 605 次失败后选择放弃，那么也许新药的诞生还要推迟许多年，人类对抗疾病的进程也将因此放缓。** 是坚持，让他笑到了最后。

**写法三：意义分析**（这件事说明了什么？有什么价值？）
> ……制出了新药 606。**605 次失败没有击垮他，这不仅体现了一位科学家顽强的毅力，更诠释了"坚持"二字的真正内涵——在他人绝望时再多走一步。**

**学生练习**：为"勤能补拙"这一论点，用"爱迪生发明电灯做了上千次实验"的材料，写一句分析句（三种写法任选一种）。

#### 小组互评 + 展示（12 分钟）

四人一组，交换练习本，按照下列评分标准互相评价：

| 项目 | 满分 |
|-----|------|
| 论据是否真实典型 | 3 分 |
| 是否有分析句，不是单纯举例子 | 4 分 |
| 分析句是否紧扣论点 | 3 分 |

每组推选 1 份最佳作业全班展示，师生共同点评。

#### 小结 + 作业（8 分钟）

**作业**：以"责任"为话题，用 200-300 字写一个"论点 + 事实论据 + 分析"的议论文段落。

### 五、板书设计

```
事实论据的选择与使用

一、选择三原则：     二、三层结构：        三、分析三法：
  1. 真实          观点（论点）           ① 因果分析法
  2. 典型          论据（事例）           ② 假设分析法
  3. 新颖          分析（说理） ★难点    ③ 意义分析法
```

## 教案范例三：英语——定语从句（Attributive Clauses）

### 一、基本信息

| 项目 | 内容 |
|-----|------|
| 学科 | 初中英语（八年级下册） |
| 课题 | Unit 6 定语从句——who/which/that 的用法 |
| 课时 | 第 1 课时（45 分钟） |
| 授课对象 | 初中二年级学生（已掌握六大基本句型和简单句） |

### 二、教学目标

1. 学生能**识别**定语从句，准确找出先行词和关系代词
2. 学生能**正确使用** who（指人）、which（指物）、that（指人/物）引导定语从句
3. 学生能用定语从句描述人物、事物（如 "I like music that I can dance to"）

### 三、教学过程

#### Step 1: Lead-in & Presentation（10 分钟）

**教师活动**：用大屏幕展示一张"全家福"照片，用英语逐一描述：
> This is my father. He is a doctor.
> → This is my father **who** is a doctor.

> This is a book. I like it very much.
> → This is a book **which** I like very much.

引导学生观察两句合成一句的规律，呈现**定语从句**的概念：
- **先行词**：被修饰的名词/代词（the noun that comes before）
- **关系代词**：连接先行词和从句的词（who/which/that）

总结规则表格：

| 关系代词 | 指代 | 在从句中充当 |
|---------|------|------------|
| **who** | 人 | 主语 / 宾语 |
| **which** | 物 | 主语 / 宾语 |
| **that** | 人 或 物 | 主语 / 宾语 |

#### Step 2: Controlled Practice（15 分钟）

**练习 1：选择正确的关系代词**
1. I love writers _____ explain things well.（who/which）
2. We talked about the things and persons _____ we saw then.（who/that）
3. The fish _____ I cooked was delicious.（which/who）

**练习 2：把两个简单句合并成一句（带定语从句）**
1. The boy is my brother. He is wearing a blue T-shirt.
   → The boy who/that is wearing a blue T-shirt is my brother.
2. Where is the book? I bought the book yesterday.
   → Where is the book which/that I bought yesterday?

**练习 3：找错误并改正**
*The teacher which teaches us English is very kind.*
→ 错误：which 指人 → 改为 who 或 that。

#### Step 3: Real-world Communication（15 分钟）

**活动："猜猜他是谁？"（Guess Who）**

游戏规则：
- 每人在心中想一位班级里的同学或一位大家熟知的名人
- 用**三句以上带定语从句**的话进行描述，但**不能说出名字**
- 其他同学举手猜："Is he/she ...?"

**教师示范**：
> I'm thinking of a person. He is a great scientist who was born in 1879. He is the person who developed the theory of relativity. He is someone whose hair was always white and messy. Who is he?
（Answer: Albert Einstein）

学生分小组活动，然后邀请 2-3 位同学上台描述，全班猜。

#### Step 4: Summary & Homework（5 分钟）

**Homework**：
1. 完成课本练习册 P32 定语从句专项练习
2. 用定语从句写 5 个句子，描述你的家庭成员、好朋友、最喜欢的书、最喜欢的歌手、最喜欢的电影

### 四、板书设计

```
Attributive Clauses（定语从句）

┌───────────┬────────┬────────────────┐
│ 关系代词   │ 指代   │ 例句            │
├───────────┼────────┼────────────────┤
│ who       │ 人     │ The boy who... │
│ which     │ 物     │ The book which...│
│ that      │ 人/物  │ Everything that...│
└───────────┴────────┴────────────────┘

先行词（n.）+ 关系代词 + 从句
  被修饰的          修饰限定
```

## 教案范例四：物理——牛顿第一定律

### 一、基本信息

| 项目 | 内容 |
|-----|------|
| 学科 | 初中物理（八年级） |
| 课题 | 牛顿第一定律（惯性定律） |
| 课时 | 1 课时（45 分钟） |
| 实验器材 | 斜面、小车、毛巾、棉布、木板、刻度尺、伽利略理想实验演示器 |

### 二、教学目标

1. **知识目标**：学生能准确表述牛顿第一定律的内容；理解"惯性"的概念
2. **能力目标**：学生经历"伽利略斜面实验"的探究过程，初步学习"实验 + 推理"的科学研究方法
3. **情感目标**：通过亚里士多德→伽利略→牛顿的历史脉络，感受科学发展的艰辛与乐趣，培养质疑和实证精神

### 三、教学重难点

**重点**：牛顿第一定律的内容；惯性的概念
**难点**：从斜面实验的现象推理出理想情况（没有阻力时的运动），认识到"力不是维持运动的原因，而是改变运动状态的原因"（纠正学生日常直觉的错误观念）

### 四、教学过程

#### （一）矛盾引入（5 分钟）

**情境提问**：
1. 放在讲台上的黑板擦，怎样才能让它运动起来？（用力推它）
2. 如果停止用力，黑板擦会怎样？（慢慢停下来）
3. 所以，**是不是有力物体才能运动？没有力物体就会停下来？**

→ 大部分学生凭直觉会点头同意。此时引出：
- **亚里士多德（两千多年前）的观点**：力是维持物体运动的原因（物体受力才运动，不受力就停止）。
- 这一观点统治了人们的思想将近两千年，直到伽利略提出质疑……

**设计意图**：用学生熟悉的直觉经验和科学真理制造"认知冲突"，激发探究欲望。

#### （二）实验探究：伽利略斜面小车实验（20 分钟）

**实验目的**：探究物体受到的阻力对运动的影响

**实验装置**：同一小车从同一斜面的同一高度由静止滑下，在不同粗糙程度的水平面上运动。

**步骤**：
1. 第一次：水平面铺毛巾，记录小车滑行的距离
2. 第二次：水平面铺棉布，记录滑行距离
3. 第三次：水平木板，记录滑行距离

学生分组实验，记录数据：

| 表面 | 粗糙程度 | 阻力大小 | 滑行距离 s/cm |
|-----|---------|---------|-------------|
| 毛巾 | 大 | 大 | |
| 棉布 | 中 | 中 | |
| 木板 | 小 | 小 | |

**引导讨论**：
1. 三次实验为什么让小车从**同一高度**滑下？（保证小车到水平面时的**初速度相同**，便于公平比较）
2. 三次实验的现象说明了什么？（阻力越小，滑行越远，速度减小得越慢）

**推理**（理想实验的思想）：
假设存在一种绝对光滑的水平面，阻力 = 0，那么小车会怎样？
→ 小车将以不变的速度**永远运动下去**！

→ 伽利略的结论：物体的运动不需要力来维持！力不是维持运动的原因，而是**改变运动状态**的原因。

**设计意图**：让学生亲历"控制变量实验 + 科学推理"的完整探究过程。

#### （三）牛顿第一定律的建立（10 分钟）

在伽利略等人研究的基础上，英国伟大的物理学家牛顿总结出了著名的牛顿第一定律：

> **牛顿第一定律（惯性定律）**：
> 一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态。

**关键词解读**：
- "一切物体"：没有例外，所有物体都遵守
- "没有受到力的作用"：理想条件（实际中是"合力为零"的等效情况）
- "总保持"：除非有外力改变它，否则永远保持原来的状态
- "或"：二选一——原来静止就保持静止；原来运动就保持匀速直线运动

**理解检测**：
1. 牛顿第一定律能不能直接用实验验证？（不能，是在实验基础上推理得出的。因为没有完全不受力的物体。）
2. 匀速飞行的飞机上掉下一个物体（不计空气阻力），这个物体在水平方向会怎样运动？（保持和飞机相同的速度，所以地面上的人看它是曲线，飞机上的人看它是直线下落。）

#### （四）惯性现象的解释与应用（7 分钟）

牛顿第一定律告诉我们：**一切物体都有保持原来运动状态不变的性质，这种性质叫做惯性。**

**演示实验 + 学生解释**：
1. **钢笔帽抽纸条**：纸条放在钢笔帽下，猛地一抽纸条，钢笔帽不倒（保持静止）。
2. **汽车突然启动/刹车**：乘客的反应。
   - 汽车突然启动时：乘客向**后**倾（乘客的脚随车向前，但身体上部保持静止的惯性）
   - 汽车突然刹车时：乘客向**前**倾

**生活中的惯性**：
- 利用惯性：拍打衣服除尘、跳远助跑、扔铅球
- 防止惯性危害：汽车安全带、公交车拉手

#### （五）小结 + 作业（3 分钟）

**作业**：
1. 课本对应练习题
2. 家庭小实验：找一个杯子，一张硬卡片，一枚硬币。把卡片放在杯子上，硬币放在卡片上。用手指迅速弹走卡片，观察硬币会怎样？写出你的观察和解释。

### 六、课后反思

**亮点**：小车实验学生兴趣浓厚，每个组的数据都支持了结论，效果很好。弹卡片的家庭小实验是学生回家后最常做的一个实验，第二天纷纷分享成果。

**改进点**：部分学生对"理想推理"这一步接受较慢。下节课可以用动画（Flash）模拟"越来越光滑 → 无限光滑"的渐变过程，让抽象的推理更形象化。另外，关于惯性的表述（"物体有惯性" vs "物体受到惯性作用"），应该在课堂上重点强调：惯性是**性质**，不是**力**，不能说"受到惯性力"。
