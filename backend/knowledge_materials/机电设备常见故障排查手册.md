# 机电设备常见故障排查手册

## 第一章 故障排查通用方法论

### 1.1 故障排查的核心思路（四步法）

遇到任何机电设备故障，都不要慌，按**"望→闻→问→切"**四步走：

```
┌─────────────────────────────────────────────────────┐
│  第一步：望（观察）                                    │
│  · 看外部现象：有没有冒烟、火花、漏液、变形、断线？       │
│  · 看指示灯：电源灯亮不亮？报警灯什么颜色？             │
│  · 看显示屏：有没有错误代码提示？（Error Code）         │
│  · 看运动轨迹：走刀/运动是否卡顿、位置是否偏差？         │
│                                                       │
│  第二步：闻（听+嗅）                                    │
│  · 听声音：有没有异常的咔咔声、啸叫、摩擦声？            │
│  · 嗅气味：有没有烧焦味（电气烧损）、油味（液压泄漏）？  │
│                                                       │
│  第三步：问（调查）                                    │
│  · 问操作人员：故障发生前做了什么操作？加工什么零件？     │
│  · 问维护记录：上次保养是什么时候？之前有过什么故障？     │
│  · 查报警历史：PLC / CNC / 变频器里的历史故障记录        │
│                                                       │
│  第四步：切（检测+验证）                                │
│  · 用万用表测电压、电阻、通断                           │
│  · 用示波器看信号波形                                   │
│  · 单部件测试（替换法验证怀疑部件）                     │
│  · 手动操作测试（JOG 点动、I/O 强制输出）               │
└─────────────────────────────────────────────────────┘
```

### 1.2 故障排查的五个重要原则

| 原则 | 具体含义 | 为什么要这样做 |
|-----|---------|-------------|
| **先静后动** | 先断电静态检查（目视、测量），再通电动态观察 | 盲目通电可能扩大故障，造成二次损坏 |
| **先外后内** | 先查外部易见的原因（断线、插头松、保险丝），再拆内部 | 80% 的故障都是外部简单原因，省时省力 |
| **先机械后电气** | 先判断机械是否卡滞、是否到位，再查电气原因 | 机械卡死时强行通电会烧坏电机、驱动器 |
| **先公共后局部** | 先查公共部分（电源、气源、总开关），再查具体部件 | 公共部分问题影响范围大，优先排查 |
| **先简单后复杂** | 先排除最可能、最简单的原因，再深入复杂电路逻辑 | 简单故障概率远高于复杂故障，优先排查效率高 |

### 1.3 常见检测工具

| 工具 | 用途 | 使用要点 |
|-----|------|---------|
| **万用表** | 测电压、电流、电阻、通断 | 电压档量程选大→小；电阻档必须断电测量！ |
| **兆欧表（摇表）** | 测电机绕组对地绝缘电阻 | 绝缘电阻一般 ≥ 0.5 MΩ 才算合格 |
| **示波器** | 观察传感器信号、编码器脉冲、电源纹波 | 接地夹夹好，避免引入干扰 |
| **钳形电流表** | 不拆线直接测交流电机电流 | 夹住单根线（不要同时夹零火线），读数准确 |
| **红外测温仪** | 测电机、轴承、接触器、端子的温度 | 异常过热（>80℃）往往预示即将故障 |
| **听诊棒（螺丝刀听）** | 听轴承、齿轮箱内部声音 | 螺丝刀柄贴耳朵，刀头贴设备，听内部异响 |
| **备件替换法** | 用好的零件替换怀疑的零件 | 前提是判断准确，避免好零件也被烧坏 |

## 第二章 电气类常见故障

### 2.1 断路故障（线路断开）

#### 现象

- 设备完全没电，电源指示灯不亮
- 某一个电机/气缸/传感器完全不动作
- 保险丝/断路器跳闸

#### 原因分析

| 可能原因 | 概率 | 排查方法 |
|---------|------|---------|
| **电源插头/插座接触不良或断线** | 高 | 插头拔插、目视检查；万用表测插座电压 |
| **保险丝熔断** | 高 | 目视保险丝是否烧断；万用表通断档测 |
| **断路器跳闸** | 高 | 配电箱检查断路器手柄位置 |
| **接线端子松动/发热烧断** | 中 | 目视端子排有无发黑、烧蚀；螺丝刀紧一紧 |
| **电缆内部断线（拖链中反复弯折）** | 中 | 万用表测电缆两端通断；或用替换法换电缆 |
| **急停按钮被按下未复位** | 极高 | 检查各急停按钮，右旋复位 |
| **安全门开关未闭合** | 高 | 检查各安全门是否关好，开关是否到位 |

#### 排查步骤

```
总电源 → 断路器 → 保险丝 → 端子排 → 电缆线 → 执行部件
  ↓        ↓        ↓        ↓        ↓        ↓
测电压    复位     通断      紧螺丝    通断    两端电压
```

#### 示例排查流程（某伺服电机完全不转）：
1. 查电柜伺服驱动器是否通电？（显示面板亮吗？）→ 不亮 → 查伺服驱动器电源进线端子电压 → 无电压 → 查上游接触器 → 接触器吸合了但输出端无电 → 拆下接触器发现触点烧蚀 → **结论：接触器触点损坏，更换接触器。**

### 2.2 短路故障

#### 现象

- 一送电就"啪"的一声，断路器跳闸、保险丝爆断
- 严重时伴随冒烟、火花、烧焦味

#### 原因分析

| 可能原因 | 排查方法 |
|---------|---------|
| **火线与零线/地线相碰（相线对地短路）** | 断电后万用表电阻档测相线对地电阻，正常应为 MΩ 级，短路时为 0Ω 或很小 |
| **电机绕组烧毁相间短路** | 兆欧表测三相绕组之间、对地绝缘电阻；三相电阻严重不平衡 |
| **变压器/电磁阀线圈烧毁短路** | 测线圈电阻，正常为几十~几百Ω，短路时接近 0 |
| **接线端子处两根线裸露部分相碰** | 目视端子排，尤其导线接头剥线过长的情况 |
| **直流电源正负极接反或碰线** | 断电后测量 DC 电源输出端电阻 |
| **变频器/驱动器内部 IGBT 模块击穿** | 拆下驱动器输出端子，测相间电阻 |

#### 严重警告！

> **发生短路跳闸后，千万不要强行送电！**
> - 必须先找到短路原因并排除
> - 有些师傅为了"测试"反复合闸，可能导致：
>   - 电缆起火（绝缘熔化冒烟燃烧）
>   - 变频器/伺服驱动器整模块烧毁（维修成本极高）
>   - 严重时甚至引发电气火灾

### 2.3 接触不良故障

这类故障最隐蔽——**时好时坏、振动一下就好一会儿、出问题拍一下又好了**。

#### 现象

- 设备运行中偶尔报警停机，断电重启又好
- 振动大的工位容易出问题
- 有时某轴位置偶发偏差，每次值还不一样

#### 原因分析

| 常见位置 | 原因 |
|---------|------|
| **航空插头/圆形连接器** | 针脚氧化、插芯松动、电缆根部断线（反复弯折造成内部铜丝断裂只剩几根） |
| **接线端子排** | 螺丝没拧紧、长期发热氧化导致接触电阻增大 |
| **继电器/接触器触点** | 触点长期使用烧蚀、氧化、接触电阻变大 |
| **编码器/光栅尺读数头插头** | 机床长期振动导致插头微松动 |
| **接插式继电器底座** | 底座弹片松动 |

#### 排查方法

1. **振动法**：用绝缘棒（螺丝刀塑料柄）轻轻敲击怀疑的部位，看是否复现故障
2. **测量法**：在故障状态下测量电压——接触不良的地方"该有电压的地方没有、时有时无"
3. **替换法**：换一根新电缆 / 换一个新插头 / 换一个新继电器

#### 修复方法

- 接触不良的**接线端子**：拆下接线，砂纸打磨氧化层，重新压接（必要时换线鼻子）
- 接触不良的**插头**：清洁针脚（无水酒精+棉签），插芯用尖嘴钳夹一下增加夹紧力；严重时更换整根线
- 接触不良的**继电器/接触器**：触点轻微烧蚀用细砂纸打磨，严重必须更换（因为触点表面的银合金镀层磨掉后再打磨只会更差）

### 2.4 PLC 常见报警及处理（以西门子 S7-1200 为例）

| 报警现象 | 可能原因 | 处理方法 |
|---------|---------|---------|
| CPU STOP 灯亮，运行灯灭 | 程序扫描时间超限、存储卡问题、严重编程错误 | 在线连接 CPU，查看诊断缓冲区（Diagnostic Buffer），根据错误代码定位 |
| SF 红灯亮（系统故障） | 模块故障、信号板问题、IO 组态不一致 | 看诊断缓冲区哪个模块故障；确认硬件组态和实际模块型号完全一致 |
| BF 灯闪烁（总线故障） | Profinet / DP 通信断线、从站断电 | 检查网线/DP 线、从站电源、交换机指示灯 |
| 某数字量输入点始终 0 | 现场传感器没供电、线断、传感器坏 | 万用表量传感器电源电压、PLC 输入端子电压；短路输入点对 24V 看 PLC 上灯是否亮 |
| 某数字量输出点始终不输出 | 程序逻辑未满足、输出点烧毁、公共端 COM 没接 | 先 PLC 软件"强制"输出 ON，看灯亮不亮；灯亮但外部没电 → 检查 COM 端和外部接线 |

## 第三章 机械类常见故障

### 3.1 磨损类故障

#### （一）轴承磨损

轴承是旋转机械的"关节"，故障概率最高。

**阶段症状**（由轻到重）：

| 阶段 | 现象 | 温度 | 噪声 |
|-----|------|------|------|
| 初期磨损 | 正常运转 | 正常 | 轻微均匀"沙沙"声 |
| 中期 | 滚道开始有点蚀 | 比平时高 5~10℃ | 周期性"咯噔咯噔"声，随转速变化 |
| 后期 | 滚动体/滚道严重损伤 | 烫手（>80℃） | 尖锐啸叫或咔咔声，振动大 |
| 末期 | 抱死（卡死） | 冒烟、烧红 | 电机转不动，过载报警 |

**检测方法**：
- **听**：螺丝刀贴在轴承座上听——均匀沙沙声 = 正常；周期性咯噔声 = 滚道有点蚀；金属摩擦尖叫声 = 缺油或严重磨损
- **摸**：手背接触轴承座（手背上对温度敏感）——能长时间忍受 = < 60℃；只能忍受 3 秒 ≈ 70℃；一碰就缩手 = > 80℃
- **测**：红外测温仪定期记录同一位置温度，建立温度趋势曲线

**常见原因**：
1. **缺油 / 油脂干涸** → 定期加润滑脂（注意不要加太多，填满轴承空腔 1/2~2/3 即可，多了反而发热）
2. **油脂牌号不对** → 高温环境用了普通润滑脂，会很快变稀流失
3. **安装不当** → 敲内圈装轴、敲外圈装孔，不能同时敲内外圈；配合过盈量过大
4. **密封不好进水/进粉尘** → 检查密封圈，有水冲洗的工位要用双面密封轴承（2RS）
5. **过载/预紧过大** → 轴承载荷超过额定值，寿命急剧下降

#### （二）齿轮磨损 / 齿面点蚀

**现象**：
- 齿轮箱运行噪音变大，出现明显"嗡嗡"声 + 周期性敲击声
- 箱体内有金属粉末（放油时底部磁铁上吸附很多铁粉）
- 严重时打齿——一声巨响后传动轴不转了

**检查方法**：
- 打开齿轮箱观察孔或上盖，目视检查齿轮工作面：
  - 齿面有点蚀凹坑（小麻点）→ 中度磨损
  - 齿厚明显变薄、齿顶变尖 → 严重磨损
  - 某一两个齿缺了一块 → 打齿，必须立即换齿轮

**常见原因**：
- 润滑油不足或油品不对（工业齿轮油有 ISO VG 黏度等级）
- 齿轮啮合侧隙不合适（太大冲击、太小发热）
- 轴弯曲、两轴不平行导致局部啮合

### 3.2 松动类故障

#### 现象

- 设备运行时振动大、噪音大
- 偶发撞击声"哐当"一下
- 加工件尺寸不稳定、偏差忽大忽小

#### 常见松动位置

| 松动部位 | 后果 | 处理方法 |
|---------|------|---------|
| **地脚螺栓松动** | 整个设备振动、位移 | 重新找正，按对角线顺序紧固，加防松垫圈/涂螺纹胶 |
| **联轴器螺栓松动/弹性体损坏** | 电机侧和负载侧不同轴，冲击大 | 紧固螺栓，更换弹性联轴器的聚氨酯梅花垫 |
| **丝杠/导轨安装螺栓松动** | 工作台走位偏差、爬行 | 按照厂家推荐扭矩重新紧固，注意拧紧顺序（从中间向两端） |
| **夹爪/卡盘卡爪松动** | 工件装夹不牢、飞出危险 | 检查夹紧行程，清理卡爪内铁屑，更换磨损卡爪 |
| **同步带轮顶丝松动** | 轴转带轮转不同步，丢步 | 重新对正键槽位置，紧顶丝，必要时加键 |

### 3.3 对中不良（传动系统不对心）

#### 现象

- 电机/泵/压缩机运行时轴承发热、振动大
- 联轴器很快就坏（梅花垫/弹性体几个月就碎）
- 油封很快就漏油

#### 分类

| 不对中类型 | 描述 | 联轴器允许补偿（弹性联轴器） |
|-----------|------|------------------------|
| **平行不对中** | 两轴轴线平行但不重合（错开） | 通常 ≤ 0.2 mm |
| **角度不对中** | 两轴轴线相交成一个角度 | 通常 ≤ 0.5°（约 1 mm / 100 mm） |
| **综合不对中** | 两者同时存在 | |

#### 校正方法（对中找正）

1. **直尺+塞尺法（简单精度低）**：直尺靠在两个联轴器外圆上，看四周间隙是否一致
2. **百分表法（双表找正，常规方法）**：
   - 一块表测径向（外圆跳动）→ 调平行不对中
   - 一块表测端面（平面跳动）→ 调角度不对中
   - 先调电机前后脚高低（垫垫片），再调左右位置
3. **激光对中仪（高精度）**：激光打在靶上，仪器自动算出垫多高垫片、移动多少毫米

> 对中是技术活，**热态对中**比冷态更重要——设备运行起来发热后会膨胀，所以冷态时要留补偿量。

## 第四章 传感器失效故障

### 4.1 接近开关 / 光电开关失效

#### 现象

- 本该检测到物体时没信号（漏检）
- 没有物体却一直有信号（误检）

#### 原因排查

| 现象 | 可能原因 | 排查方法 |
|-----|---------|---------|
| 完全没信号（灯不亮） | 电源没供上 / 极性接反 | 万用表测开关供电端电压：Brown（棕）+24V，Blue（蓝）0V |
| | 输出线接错 / 上拉电阻没接 | NPN 输出低电平有效，PNP 输出高电平有效 |
| 漏检（物体过来灯不亮） | 安装距离太远（超出检测距离） | 接近开关按 80% 额定检测距离安装，留余量 |
| | 传感器前面被铁屑/油污/粉尘遮挡 | 清洁传感器检测面 |
| | 检测物体材料不对（电感式只检测金属） | 如铝、铜、不锈钢的检测距离比钢小很多 |
| 误检（没有物体灯常亮） | 旁边有金属物体干扰 | 传感器和周围金属保持 ≥ 2 倍检测距离 |
| | 多个传感器并排安装互相干扰 | 传感器之间保持 ≥ 2 倍检测距离 |
| | 阳光/强光直射光电开关（光饱和） | 加遮光罩、更换抗强光型号 |
| 输出信号闪烁不稳定 | 电缆接触不良 / 传感器内部电路老化 | 换电缆 / 换传感器测试 |

#### 三线制开关接线口诀（很重要！）：

```
棕（Brown）接 +24V 正极
蓝（Blue）接 0V   负极
黑（Black）接输出信号线（NPN 型：输出导通时黑线 = 0V；PNP 型：输出导通时黑线 = +24V）
```

### 4.2 编码器 / 光栅尺失效

#### 现象

- 数控机床位置不准，每次偏差不一样（随机偏差）
- 伺服电机报警：**编码器信号丢失、过速、跟随误差过大**
- 回零不准，偶尔过冲或回不到零

#### 原因分析

| 可能原因 | 排查 / 处理 |
|---------|-----------|
| **编码器连接轴断键 / 顶丝松** | 编码器轴和电机轴之间有相对滑动 → 断电手转电机轴，看读数变化是否 1:1 对应 |
| **编码器线接触不良** | 航空插头针脚氧化、拖链中电缆芯线断裂 → 换线测试 |
| **光栅尺读数头脏污 / 有划痕** | 读数头镜头沾了切削液/油污 → 用无尘棉签 + 无水酒精轻轻擦光栅尺面和读数头 |
| **强电磁干扰** | 变频器、电焊机启停干扰编码器信号 → 编码器线用屏蔽电缆，屏蔽层单端接地；远离动力线布线 |
| **机械冲击损坏** | 机床碰撞导致读数头与尺身擦伤 → 看尺面有没有划痕、压痕，严重必须更换 |

## 第五章 机电设备常见故障速查表

### 5.1 数控机床 CNC 常见故障

| 故障现象 | 最可能原因（按概率从高到低） | 排查要点 |
|---------|------------------------|---------|
| **通电后系统黑屏无反应** | 1. 外部 380V/220V 电源未供<br>2. 系统开关电源损坏<br>3. 急停回路未通<br>4. 系统主板保险丝熔断 | 先量电源端子电压；再查开关电源 24V 输出；再查系统内部保险丝 |
| **回原点时撞硬限位** | 1. 减速开关坏或挡片松（没减速，直接撞限位）<br>2. 原点参数设置错<br>3. 伺服参数位置增益过高过冲 | 手动模式按减速开关观察 PLC 输入信号有没有变化；检查挡片位置 |
| **加工尺寸偏差（每次同方向定值偏差）** | 1. 丝杠反向间隙大（机械磨损）→ 用百分表测反向间隙值，在参数里补偿<br>2. 丝杠螺母支座松动<br>3. 刀补或工件坐标系输错 | 先查刀补坐标，再测机械间隙 |
| **加工表面波浪纹 / 振纹** | 1. 主轴轴承磨损、间隙大<br>2. X/Y 轴导轨镶条间隙大<br>3. 切削参数不合理（切深/进给/转速共振）<br>4. 伺服位置环增益太低或太高 | 手转主轴感受轴向窜动和径向跳动；看切削振纹频率和进给是否对应 |
| **主轴异响 + 发热** | 1. 主轴轴承缺油 / 磨损<br>2. 主轴皮带过紧 / 过松<br>3. 主轴电机轴承坏 | 听哪个部位的声音（主轴头 vs 电机）；红外测温度点对比 |
| **换刀卡刀 / 刀库乱刀** | 1. 换刀原点位置错<br>2. 刀库计数传感器脏污 / 坏<br>3. 气缸 / 液压压力不足<br>4. 刀具超重 / 超长 | 刀库回零重新校准刀号；检查气压/液压压力；检查换刀时主轴定向是否准确 |

### 5.2 变频器 / 伺服驱动器常见报警

#### 三菱 / 安川 / 台达等品牌常见报警对照表（通用）

| 报警代码（通用叫法） | 含义 | 最可能原因 | 处理步骤 |
|-------------------|------|-----------|---------|
| **OC / OC1 / OC2 / OC3** | 过流（Over Current） | 输出端短路、电机绝缘坏、加速时间太短、IGBT 坏 | 1. 拆电机线空载运行，判断内部还是外部<br>2. 测电机绝缘和相间电阻<br>3. 延长加速时间 |
| **OV / OV1** | 过压（Over Voltage） | 电网电压过高、减速时间太短（能量回馈）、制动电阻坏 | 1. 测输入电源电压<br>2. 延长减速时间<br>3. 检查制动电阻阻值是否正确、接线 |
| **UV / UV1** | 欠压（Under Voltage） | 输入电源缺相、进线接触器触点坏、保险丝断、整流模块坏 | 1. 测输入三相电压是否都有 380V<br>2. 检查接触器/断路器 |
| **OL / OH** | 过载 / 过热（Over Load / Over Heat） | 负载卡住、电机力矩不足、冷却风扇坏、环境温度高 | 1. 断电手盘机械是否卡滞<br>2. 清散热器灰尘、检查风扇是否转<br>3. 降低负载或选大一档驱动器 |
| **AL-**（编码器报警类） | 编码器信号异常 | 编码器线断/接触不良、编码器损坏、电机码盘被撞坏 | 换编码线 → 换电机编码器 → 最后才怀疑驱动器接口坏 |
| **EF / E.6** | 外部故障 / 紧急停止 | 外部急停按下、安全回路断开 | 检查所有急停按钮、安全门开关、外部端子急停输入 |

### 5.3 液压系统常见故障

| 故障现象 | 原因 | 排查 |
|---------|------|------|
| **系统无压力 / 压力不够** | 1. 油泵旋向错（电机反转）<br>2. 溢流阀卡滞（溢流阀弹簧卡了，压力溢走了）<br>3. 液压油不够，油泵吸空<br>4. 油泵内部磨损严重（容积效率低） | 1. 听油泵声音："咕噜咕噜"响 = 吸空，检查油位和吸油过滤器<br>2. 拧溢流阀调节杆看压力是否变化 → 完全没变化 = 溢流阀卡死，拆洗 |
| **液压缸爬行 / 速度慢** | 1. 液压缸内有空气（最常见）→ 来回动作数次排气，或开排气阀<br>2. 导轨/活塞杆润滑不好，阻力大<br>3. 液压缸密封件磨损，内泄大 | 排空气 → 检查密封内泄（堵有杆腔油口，加压看是否慢慢后退） |
| **液压油泄漏严重** | 1. 管接头松动 → 拧紧（注意密封用生料带只能缠在外螺纹前 2/3，别进管内）<br>2. 密封件（O 圈、油封）磨损老化 → 更换<br>3. 焊缝/管接头焊接处开裂 → 拆下来补焊 | 注意：漏油一定要处理，油液很滑容易绊倒人，而且成本高又污染环境 |

### 5.4 气动系统常见故障

| 故障现象 | 原因 | 排查 |
|---------|------|------|
| **气缸完全不动作** | 1. 气源没气（空压机关了 / 气管漏气严重压力不够）<br>2. 电磁阀没通电 / 线圈坏<br>3. 气缸机械卡死<br>4. 磁性开关位置不对（有互锁逻辑时） | 1. 看气源处理器上压力表是否 ≥ 0.5 MPa<br>2. 给电磁阀手动按钮（小一字槽）按下去看动不动 → 动 = 电气问题；不动 = 机械/气路问题 |
| **气缸动作慢 / 力不够** | 1. 气源压力不够<br>2. 气缸速度调节阀（节流阀）开太小<br>3. 气缸内活塞密封圈磨损内泄 | 调压力 → 调节流阀 → 还不行拆缸看密封 |
| **电磁阀一直嗡嗡响，不换向** | 1. 电磁阀线圈电压不对（AC220V 线圈通了 DC24V 等）<br>2. 阀芯被杂质卡滞 → 拆阀体清洗阀芯，用压缩空气吹<br>3. 线圈烧了 → 测线圈电阻，正常 AC220V 线圈几 kΩ，DC24V 线圈约几十 Ω，烧了则无穷大或接近 0 |
| **压缩空气中含水多，冬天管路结冰** | 1. 空气压缩机后部没装冷干机 / 干燥器<br>2. 储气罐没定期排水 → 储气罐底部有手动排水阀，**每班排水 1 次** | 装冷冻式干燥机 + 过滤器三联件；检查自动排水器是否正常工作 |
