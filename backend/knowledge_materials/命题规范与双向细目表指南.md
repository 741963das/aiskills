# 命题规范与双向细目表制作指南

## 第一章 命题的基本原则

命题（出题）是教学测量与评价的核心环节。一份高质量的试卷应该具有**科学性、公平性、准确性、区分度**。命题工作必须遵循以下六大原则：

### 1.1 科学性原则

**核心要求**：试题内容正确、表述准确、答案没有争议。

具体表现：
- 试题本身不能有知识性错误（如：数学题的条件矛盾、物理题的数据不符合实际）
- 语言表述要清晰、无歧义，避免使用生僻字和模糊词
- 选择题的正确答案唯一且确定；参考答案评分标准合理

**反例**：
- 一道数学填空题"圆的周长总是直径的 ______ 倍"，参考答案写"π"，但学生填"3.14"是否算对？——命题时应明确："用π表示"或"保留两位小数"。
- 物理题中给出的数据互相矛盾：物体质量 10kg，体积 1m³，问密度？学生算出 10 kg/m³ 但实际不可能有这么轻的"物体"。

### 1.2 公平性原则

**核心要求**：试题面向全体考生，不偏向任何特定群体。

具体表现：
- 试题涉及的情境、材料应为全体考生熟悉，避免地域差异、城乡差异、性别差异带来的不公平
- 不出偏题、怪题、与课程无关的题
- 不出需要课外特殊知识才能解答的题（除非明确标注"拓展题"）

**反例**：
- 考"滑雪运动中的摩擦力问题"——南方学生可能从未见过雪，理解情境困难，对他们不公平。
- 考"高尔夫球杆的杠杆原理"——缺乏生活经验的学生难以理解。
- 作文题"记一次难忘的出国旅行"——大部分学生没有出过国，无法真实写作。

### 1.3 全面性原则（覆盖面）

**核心要求**：试题要覆盖教学内容的主要知识点，同时兼顾各能力层次。

具体做法：
- 重点知识重点考，次要知识兼顾考
- 严格按照课程标准的教学要求命题，不能只盯着某几章反复出题
- 借助**双向细目表**（本章第三节重点讲）保证知识点和能力层次的全面覆盖

**常见错误**：一份 100 分的数学试卷中，80 分都考"二次函数"一章，其他各章总和才 20 分——覆盖面严重不足。

### 1.4 层次性原则（区分度）

**核心要求**：试题难度要有梯度，能区分不同水平的学生。

通常的难度分布（建议比例）：

| 难度层级 | 难度范围 | 比例 | 定位 |
|---------|---------|------|------|
| 容易题 | P ≥ 0.8 | 约 60% | 基础知识过关，多数学生能得分 |
| 中等题 | 0.5 ≤ P < 0.8 | 约 30% | 应用分析能力，拉开中等与薄弱的差距 |
| 较难题 | P < 0.5 | 约 10% | 综合创新能力，区分优秀学生 |

> **难度（P）** = 该题的平均得分 / 该题的满分值。
> 如：一道 10 分题，学生平均得分 7.5 分，则难度 P = 0.75（属于中等偏易）。
> P 越大，题目越简单；P 越小，题目越难。

**区分度（D）**：区分不同水平考生的能力。通常用"高分组（前 27%）通过率 - 低分组（后 27%）通过率"计算，D ≥ 0.4 为优秀。

### 1.5 规范性原则

**核心要求**：试卷格式规范、表述规范、排版规范。

具体包括：
- 字体字号：标题黑体、宋体正文，标点符号使用规范（中文全角）
- 图形图表：清晰、标注明确、与题干对应
- 分值分布：试卷标题、各大题分值、总分标注清楚
- 页码编号：每大题有大题号，每小题有序号，不重号不错号

### 1.6 适切性原则

**核心要求**：试题量与考试时间匹配，整体难度符合学情。

- 题量过大 → 学生做不完，测不出真实水平
- 题量过小 → 区分度低，偶然因素影响大
- 一般经验：学生做题时间 ≈ 教师做题时间 × 2~3

## 第二章 各题型命题规范

### 2.1 选择题（客观题）

#### 结构
由**题干**（提出问题或写出不完整的句子）和**选项**（若干备选答案，含正确项和干扰项）组成。

#### 命题规范

**1. 题干的编写**
- 题干本身必须是一个意思完整、表述清晰的问题或陈述
- 尽量使用肯定式陈述，避免否定式（如必须用否定式，要把"不"字加粗或下划线提醒）
- 题干中要包含解题的全部必要信息

**2. 选项的编写**
- 选项数量：一般 4 个（A、B、C、D），小学可 3 个
- **正确答案唯一**，不能有两个都对的情况
- **干扰项要有迷惑性**：不能一眼看穿的错误，要是学生常犯的典型错误
- 干扰项要有**似真性**：错误的选项本身要"看起来合理"，不能胡编乱造
- 各选项的长度、结构、表述方式尽量保持一致，避免给正确答案"写得更长更详细"的暗示
- 正确答案的位置随机分布（A、B、C、D 各占约 25%）
- 避免"以上都对""以上都错"的选项（除非实在需要）

**选择题优秀示例**（初二物理）：

> 题目：关于声现象，下列说法正确的是（    ）
> A. 声音在真空中的传播速度是 340 m/s   → 干扰项：速度数值对，但真空不能传声（典型错误）
> B. 只要物体在振动，人就一定能听到声音  → 干扰项：还需要介质、频率在人耳范围等
> C. 声音在固体中的传播速度一定比在液体中快  → 干扰项："一定"太绝对，有反例
> D. 中考期间学校路段禁止鸣笛，这是在声源处减弱噪声  → 正确

**选择题劣质示例**：

> 题目：下列说法正确的是（    ）
> A. 3 是奇数          → 过于简单，一眼排除
> B. 4 是奇数          → 明显错误，没有迷惑性
> C. 5 是偶数          → 明显错误
> D. 以上都不对        → 正确答案藏在这种选项里，考查不出真实水平

### 2.2 填空题

#### 命题规范

1. **空位设置合理**：空出的位置应当是该句的关键词、核心知识。不要空出无关紧要的词。
   - ✅ 好题：水的化学式是 ______。
   - ❌ 坏题：水的化______式是 H₂O。

2. **每个空考查一个明确的知识点**，避免一个空要求填多个词（容易造成歧义）。

3. **空位长度一致**：不要因为答案字数多就画长横线，字数少就画短横线——这会给学生暗示。统一用 ______（4~6 个下划线）。

4. **避免抄课本原句**：鼓励理解性填空，不要鼓励"把课本背下来"。

5. **参考答案明确**：可能有多种正确答案的，要在参考答案中全部列出。

**示例**：
> 请写出符合下列要求的物质（用化学式填空）：
> （1）密度最小的气体 ______；      （参考答案：H₂）
> （2）空气中含量最高的气体 ______；（参考答案：N₂）
> （3）可用于人工降雨的氧化物 ______；（参考答案：CO₂，写"干冰"也算对）

### 2.3 简答题（问答题）

#### 命题规范

1. **问题明确，作答要求具体**：
   - ✅ 好题："请从**经济、政治、思想文化**三个角度分析辛亥革命的历史意义，**每个角度至少写出一条**。"
   - ❌ 坏题："谈谈你对辛亥革命的看法。"（太宽泛，学生不知道写什么）

2. **开放性与限制性结合**：既有学生发挥空间，又有明确的评分要点。

3. **一题多问的，标明每题分值**。

### 2.4 计算题

#### 命题规范

1. **给出的已知条件应当充分、不冗余、不矛盾**。
2. **数据要符合实际**：如一个人体重 500N（合理），但不能 5000N（500kg，不合理）。
3. **分步设问，由易到难**：
   - 第（1）问：直接代公式，基础
   - 第（2）问：简单变形应用
   - 第（3）问：综合分析，较难
4. **评分标准要细化到步骤分**：
   例：8 分计算题评分细则：
   - 正确写出公式：2 分
   - 代入数据正确：2 分
   - 计算过程正确：2 分
   - 结果正确 + 单位：2 分

### 2.5 论述题 / 作文题

#### 命题规范

1. **题意清晰，审题门槛低**：不要让学生把大量时间花在"猜题"上。
2. **制定详细的评分量表（Rubric）**，按等级评分，不能凭感觉打分数。
3. 作文题应注意**文体明确**（记叙文/议论文/说明文），**字数要求合理**。

## 第三章 双向细目表的制作方法

### 3.1 什么是双向细目表？

**双向细目表**（Two-way Specification Table）是一种用于**规范命题**的工具。它以表格形式列出：
- **纵向（行）**：考查的知识点（教学内容）
- **横向（列）**：考查的能力层次（如布卢姆六层次）
- **表格内容**：各知识点×各能力层次对应的**题量**或**分值**

双向细目表是命题的"设计图纸"，可以保证：
- 知识点覆盖面：不偏不漏
- 能力层次合理：不是只考死记硬背
- 分值权重科学：重点章节重点考
- 避免重复：各题考查点不重复

### 3.2 双向细目表的制作步骤

#### 第一步：确定考试的总目标与性质

先回答以下问题：
- 是什么考试？（单元测验 / 期中 / 期末 / 中考模拟）
- 考哪些章节？（内容范围）
- 总分多少？考试时长？
- 难度目标？（单元测验简单一些，期末适中）
- 题型结构？（如：选择题 30 分、填空 20 分、计算 30 分、解答 20 分）

#### 第二步：列出知识点清单（纵向）

根据教材章节和课程标准，把考试范围内的知识点一一列出。可以按照"章→节→知识点"的层级组织。

**示例**：人教版九年级物理"欧姆定律"单元知识点清单：
1. 电流与电压、电阻的关系（探究实验）
2. 欧姆定律的内容与公式 I = U/R
3. 欧姆定律的变形公式应用（U = IR, R = U/I）
4. 伏安法测电阻（实验原理、电路图、步骤、误差分析）
5. 电阻的串联与并联
6. 串联电路的分压特点
7. 并联电路的分流特点
8. 欧姆定律的综合应用（动态电路、故障分析）

#### 第三步：列出能力层次（横向）

一般选用布卢姆认知领域六层次，也可以根据学科特点适当简化为：
- 基础题（记忆/理解）≈ 60%
- 中档题（应用/分析）≈ 30%
- 难题（评价/创造）≈ 10%

或者按照学科常用的能力要求：
- 数学：了解/理解/掌握/灵活运用
- 语文：识记/理解/分析综合/表达应用/鉴赏评价

#### 第四步：分配分值权重

分值权重的确定依据：
- **教学时数**：花的课时多的章节 → 权重高
- **知识重要性**：重点、难点、核心知识 → 权重高
- **课标要求**：课标要求"掌握"的 → 权重高；"了解"的 → 权重低

**示例**："欧姆定律"单元，假设总分 100 分：

| 课时权重分配（假设总课时 8 节） |
|--------------------------|
| ① 电流与电压电阻关系（1 课时）→ 约 12 分 |
| ② 欧姆定律内容（1 课时）→ 约 12 分 |
| ③ 变形公式应用（1.5 课时）→ 约 18 分 |
| ④ 伏安法测电阻（2 课时）→ 约 25 分（重点实验，权重大） |
| ⑤ 串并联电阻（1 课时）→ 约 13 分 |
| ⑥ 分分压分流（1 课时）→ 约 10 分 |
| ⑦ 综合应用（1.5 课时）→ 约 10 分 |

#### 第五步：把分值分配到每个单元格（知识点×能力层次）

先分知识点的总分，再根据这个知识点适合考什么能力，把分数分到各列。

#### 第六步：核查总分数、总题量，检查平衡

完成后检查：
- 各行之和（知识点总分）是否符合预设权重？
- 各列之和（能力层次总分）是否符合难度分布？
- 总分是否等于预设总分（如 100 分）？

### 3.3 双向细目表完整示例

**示例：高二数学《数列》单元测验双向细目表（总分 100 分）**

| 知识点 | 记忆理解 | 应用 | 分析 | 综合创造 | 合计 |
|-------|---------|------|------|---------|------|
| **1. 数列的概念与简单表示** | 选择×1（5分） | 填空×1（5分） | | | 10分 |
| **2. 等差数列的定义与通项** | 选择×1（5分） | 填空×1（5分） | | | 10分 |

| **4. 等比数列的定义与通项** | 选择×1（5分） | 填空×1（5分） | 解答×1（8分） | | 18分 |
| **5. 等比数列前 n 项和** | | 解答×1（12分） | | | 12分 |
| **6. 等差等比的判定与性质** | | | 选择×1（5分） | | 5分 |
| **7. 数列求和方法（裂项、错位等）** | | | 解答×1（10分） | 解答×1（10分） | 20分 |
| **8. 数列的实际应用** | | | | 解答×1（5分） | 5分 |
| **9. 递推数列综合** | | | | 解答×1（10分） | 10分 |

- 基础题（记忆理解 + 应用）= 67% → 符合约 60-70% 的容易和中等题
- 中档（分析）= 23%
- 难题（综合创造）= 10%
- 重点知识（等比数列、数列求和）分值明显偏高，符合其教学重要性

### 3.5 制作双向细目表的常见问题

#### 问题 1：权重分配不合理，重点章节分值太少

**修正**：重新查看课标和教学时数，核心章节分值不能低于它的重要性。

#### 问题 2：能力层次只集中在低层次（记忆/理解），没有高阶思维题

**修正**：每单元至少有 1-2 道综合/分析/应用题。数学/物理可以设计综合压轴题，语文可以设计鉴赏与写作题。

#### 问题 3：同一知识点在多道题中重复考查，而有些知识点一道题都没出

**修正**：这正是双向细目表要避免的问题——填完表后检查每行的分值，若为 0 说明没覆盖，若过高可能重复。

## 第四章 命题质量的检查清单

命题完成后，教师应按照以下清单自查一遍：

### 4.1 科学性检查

- [ ] 每道题的知识点是否正确，有没有科学错误？
- [ ] 题目条件是否充分、无矛盾？
- [ ] 选择题是否只有一个正确答案，其他选项有没有争议？
- [ ] 答案和评分标准是否明确、没有模糊地带？

### 4.2 规范性检查

- [ ] 题目文字是否通顺、无歧义、无错别字？
- [ ] 标点符号、数字单位、字母大小写是否规范？
- [ ] 图表是否清晰、与题干对应？
- [ ] 题号是否连续？大题小题编号是否规范？
- [ ] 分值标注是否清楚，总分是否无误？

### 4.3 适切性检查

- [ ] 题量是否与考试时间匹配？（自己先完整做一遍计时）
- [ ] 难度分布是否符合预设（容易 60%、中等 30%、难 10%）？
- [ ] 有没有偏题、怪题？
- [ ] 素材是否公平、适合全体学生？

### 4.4 覆盖面检查

- [ ] 是否按双向细目表命题？
- [ ] 重点章节分值是否足够？
- [ ] 是否有某知识点在多道题中重复考查？
- [ ] 是否有重要知识点完全没覆盖？

> **建议**：重要考试可以采用"多人命题 + 审题人制度"——命题人不出题时自己审题，或请其他教师审题，因为自己出的题自己往往看不出问题。
