# 高等数学第一章：函数与极限讲义

## 第一节 函数的概念

### 1.1 函数的定义

设数集 D ⊂ R，则称映射 f: D → R 为定义在 D 上的**函数**，通常记为：

```
y = f(x),  x ∈ D
```

其中 x 称为**自变量**，y 称为**因变量**，D 称为函数的**定义域**，记作 D_f。

函数值 f(x) 的全体所构成的集合称为函数的**值域**，记作 R_f 或 f(D)：

```
R_f = f(D) = { y | y = f(x), x ∈ D }
```

### 1.2 函数的两个要素

函数的定义包含两个要素：**定义域**和**对应法则**。

- **定义域相同**且**对应法则相同**的两个函数是相同的函数。
- 函数的表示法只与定义域和对应法则有关，与用什么字母表示无关。

### 1.3 常见函数类型

| 函数类型 | 表达式 | 定义域 | 值域 |
|---------|--------|--------|------|
| 常数函数 | y = C | R | {C} |
| 幂函数 | y = x^α (α为常数) | 随α变化 | 随α变化 |
| 指数函数 | y = a^x (a>0, a≠1) | R | (0, +∞) |
| 对数函数 | y = log_a x (a>0, a≠1) | (0, +∞) | R |
| 三角函数 | sin x, cos x, tan x, ... | 各不同 | 各不同 |

### 1.4 例题

**例 1**：求函数 f(x) = √(4-x²) + 1/√(x-1) 的定义域。

解：要使函数有意义，需满足：
- 4 - x² ≥ 0，即 x² ≤ 4，得 -2 ≤ x ≤ 2
- x - 1 > 0，即 x > 1

取交集得定义域为：D = (1, 2]

**例 2**：判断下列函数是否相同：
- f(x) = x 与 g(x) = √x²
- f(x) = lg(x²) 与 g(x) = 2lgx

解：
- f(x) = x，g(x) = |x|，对应法则不同，故不同。
- f(x) 定义域：x ≠ 0；g(x) 定义域：x > 0，定义域不同，故不同。

### 1.5 常见错误

❌ **错误 1**：忽略定义域的限制，例如认为 lg(x²) = 2lgx 对所有 x 成立。
✅ 正确：仅当 x > 0 时等号成立。

❌ **错误 2**：将 f(x+1) 理解为 f 乘以 (x+1)。
✅ 正确：f(x+1) 表示复合函数，将 x 替换为 x+1。

## 第二节 数列的极限

### 2.1 数列极限的定义（ε-N 定义）

设 {x_n} 为一数列，a 为常数。若对于**任意给定的正数 ε**（无论它多么小），**总存在正整数 N**，使得当 n > N 时，不等式：

```
|x_n - a| < ε
```

都成立，则称常数 a 是数列 {x_n} 的**极限**，或称数列 {x_n} **收敛于 a**，记作：

```
lim(n→∞) x_n = a   或   x_n → a (n → ∞)
```

### 2.2 定义的几何解释

当 n > N 时，所有的点 x_n 都落在开区间 (a-ε, a+ε) 内，只有有限个点（至多 N 个）落在该区间之外。

### 2.3 用 ε-N 定义证明极限的步骤

1. 对于任意给定的 ε > 0
2. 由不等式 |x_n - a| < ε 开始分析
3. 解出 n 需要满足的条件，找到 N
4. 写出结论

### 2.4 例题

**例 3**：证明 lim(n→∞) 1/n^α = 0 (α > 0)

证明：∀ε > 0，要使 |1/n^α - 0| = 1/n^α < ε，
即 n^α > 1/ε，即 n > (1/ε)^(1/α)。

取 N = [(1/ε)^(1/α)]（取整），则当 n > N 时，有 |1/n^α - 0| < ε。
由定义，lim(n→∞) 1/n^α = 0。

**例 4**：证明 lim(n→∞) (3n+1)/(2n+1) = 3/2

证明：|(3n+1)/(2n+1) - 3/2| = |(6n+2-6n-3)/(4n+2)| = 1/(4n+2) < 1/(4n)

∀ε > 0，要使 1/(4n) < ε，即 n > 1/(4ε)。
取 N = [1/(4ε)]，则当 n > N 时，有 |(3n+1)/(2n+1) - 3/2| < ε。
故 lim(n→∞) (3n+1)/(2n+1) = 3/2。

### 2.5 常见错误

❌ **错误 1**：先指定 N，再取 ε，逻辑顺序颠倒。
✅ 正确：ε 任意给定后，再找依赖于 ε 的 N。

❌ **错误 2**：在证明过程中反向使用不等式，导致错误。
✅ 正确：可以适当放大不等式，但不能缩小。

## 第三节 函数的极限

### 3.1 x → x₀ 时函数的极限（ε-δ 定义）

设函数 f(x) 在点 x₀ 的某一去心邻域内有定义。若对于**任意给定的正数 ε**，**总存在正数 δ**，使得当 x 满足不等式：

```
0 < |x - x₀| < δ
```

时，对应的函数值 f(x) 都满足不等式：

```
|f(x) - A| < ε
```

则常数 A 称为函数 f(x) 当 x → x₀ 时的**极限**，记作：

```
lim(x→x₀) f(x) = A   或   f(x) → A (x → x₀)
```

### 3.2 注意事项

- 0 < |x - x₀| 表示 x ≠ x₀，即极限与 f(x₀) 是否存在或取何值无关。
- δ 依赖于 ε，通常 δ 随 ε 减小而减小。

### 3.3 左极限与右极限

**左极限**：x 从左侧趋近于 x₀（x → x₀⁻）：
```
lim(x→x₀⁻) f(x) = A   ⇔   ∀ε>0, ∃δ>0, 当 x₀-δ < x < x₀ 时, |f(x)-A| < ε
```

**右极限**：x 从右侧趋近于 x₀（x → x₀⁺）：
```
lim(x→x₀⁺) f(x) = A   ⇔   ∀ε>0, ∃δ>0, 当 x₀ < x < x₀+δ 时, |f(x)-A| < ε
```

**重要定理**：lim(x→x₀) f(x) 存在 ⇔ 左右极限都存在且相等。

### 3.4 例题

**例 5**：证明 lim(x→2) (2x-1) = 3

证明：|(2x-1) - 3| = |2x-4| = 2|x-2|

∀ε > 0，要使 2|x-2| < ε，即 |x-2| < ε/2。
取 δ = ε/2，则当 0 < |x-2| < δ 时，有 |(2x-1) - 3| < ε。
故 lim(x→2) (2x-1) = 3。

**例 6**：讨论 f(x) = |x|/x 当 x → 0 时的极限。

解：
- 左极限：x → 0⁻ 时，f(x) = -x/x = -1，故 lim(x→0⁻) f(x) = -1
- 右极限：x → 0⁺ 时，f(x) = x/x = 1，故 lim(x→0⁺) f(x) = 1

因为左右极限不相等，所以 lim(x→0) f(x) 不存在。

### 3.5 常见错误

❌ **错误 1**：忽视 0 < |x-x₀| 条件，将 f(x₀) 的值与极限值等同。
✅ 正确：f(x₀) 有无定义不影响极限的存在性。

❌ **错误 2**：只考虑单侧极限就断言极限存在。
✅ 正确：必须验证左右极限都存在且相等。

## 第四节 无穷小与无穷大

### 4.1 无穷小的定义

若函数 f(x) 当 x → x₀（或 x → ∞）时的极限为 0，则称 f(x) 为当 x → x₀（或 x → ∞）时的**无穷小**。

严格定义：
∀ε > 0，∃δ > 0（或 X > 0），当 0 < |x-x₀| < δ（或 |x| > X）时，有 |f(x)| < ε，则称 f(x) 为无穷小。

### 4.2 无穷大的定义

若当 x → x₀（或 x → ∞）时，|f(x)| 无限增大，则称 f(x) 为当 x → x₀（或 x → ∞）时的**无穷大**。

严格定义：
∀M > 0（无论多大），∃δ > 0（或 X > 0），当 0 < |x-x₀| < δ（或 |x| > X）时，有 |f(x)| > M，则称 f(x) 为无穷大，记作 lim f(x) = ∞。

### 4.3 无穷小与无穷大的关系

在自变量的同一变化过程中：
- 若 f(x) 为无穷大，则 1/f(x) 为无穷小；
- 若 f(x) 为无穷小且 f(x) ≠ 0，则 1/f(x) 为无穷大。

### 4.4 无穷小的运算性质

1. **有限个无穷小的和**仍是无穷小。
2. **有限个无穷小的乘积**仍是无穷小。
3. **有界函数与无穷小的乘积**是无穷小。
4. 常数与无穷小的乘积是无穷小。

### 4.5 例题

**例 7**：证明 lim(x→0) x·sin(1/x) = 0

证明：因为 |sin(1/x)| ≤ 1（有界），而 lim(x→0) x = 0（无穷小）。
由性质 3，有界函数与无穷小的乘积是无穷小，故 lim(x→0) x·sin(1/x) = 0。

**例 8**：判断 lim(x→∞) x·sinx 是否为无穷大？

解：取 x_n = 2nπ，则当 n → ∞ 时，x_n → ∞，但 x_n·sinx_n = 2nπ·0 = 0。
这说明 |f(x)| 不会总大于任意给定的 M，故不是无穷大。
（注意：这也是无界但非无穷大的经典例子。）

### 4.6 常见错误

❌ **错误 1**：将"无穷多个无穷小的和"误认为是无穷小。
✅ 反例：n 个 1/n 相加 = 1，极限不是 0。

❌ **错误 2**：混淆"无界"与"无穷大"。
✅ 正确：无穷大一定无界，但无界不一定是无穷大（如 x·sinx）。

## 第五节 极限运算法则

### 5.1 基本运算法则

设 lim f(x) = A，lim g(x) = B，则：

1. **和差法则**：lim [f(x) ± g(x)] = A ± B
2. **乘积法则**：lim [f(x) · g(x)] = A · B
3. **商的法则**：lim [f(x) / g(x)] = A / B（条件 B ≠ 0）
4. **数乘法则**：lim [c·f(x)] = c·A
5. **幂法则**：lim [f(x)]^n = A^n（n 为正整数）

### 5.2 复合函数的极限运算法则

设 y = f[g(x)] 由 y = f(u) 与 u = g(x) 复合而成。若：
- lim(x→x₀) g(x) = u₀
- 在 x₀ 的某去心邻域内 g(x) ≠ u₀
- lim(u→u₀) f(u) = A

则 lim(x→x₀) f[g(x)] = lim(u→u₀) f(u) = A

### 5.3 多项式与有理函数的极限

设 P(x) = a₀x^n + a₁x^(n-1) + ... + a_n，则：
```
lim(x→x₀) P(x) = P(x₀)
```

设 P(x), Q(x) 为多项式且 Q(x₀) ≠ 0，则：
```
lim(x→x₀) P(x)/Q(x) = P(x₀)/Q(x₀)
```

当 x → ∞ 时，有理函数的极限：
```
lim(x→∞) (a₀x^n + ... + a_n)/(b₀x^m + ... + b_m) = 
  ⎧ a₀/b₀,  当 n = m
  ⎨ 0,      当 n < m
  ⎩ ∞,      当 n > m
```

### 5.4 例题

**例 9**：求 lim(x→2) (x³-1)/(x²-3x+5)

解：这是有理函数，代入 x=2：
= (8-1)/(4-6+5) = 7/3

**例 10**：求 lim(x→1) (x²-1)/(x-1)

解：注意到 x=1 时分母为 0，不能直接代入。先因式分解：
(x²-1)/(x-1) = (x-1)(x+1)/(x-1) = x+1（x ≠ 1）
所以 lim(x→1) (x²-1)/(x-1) = lim(x→1) (x+1) = 2

**例 11**：求 lim(x→∞) (3x²+2x-1)/(2x²+x)

解：分子分母同除以最高次项 x²：
= lim(x→∞) (3 + 2/x - 1/x²)/(2 + 1/x) = (3+0-0)/(2+0) = 3/2

### 5.5 常见错误

❌ **错误 1**：在商的法则中忽略分母极限 B ≠ 0 的条件。
✅ 正确：当 B=0 时，考虑因式分解、约分或其他方法。

❌ **错误 2**：滥用极限运算法则，对 ∞-∞, 0·∞ 等未定式直接拆分。
✅ 正确：先变形（通分、因式分解、提公因子等）再求极限。

## 第六节 两个重要极限

### 6.1 第一个重要极限

```
lim(x→0) sinx/x = 1
```

**证明思路**：利用单位圆中的几何关系，建立不等式 cosx < sinx/x < 1，再用夹逼准则。

**推广形式**：若 lim α(x) = 0，则 lim sin α(x) / α(x) = 1

### 6.2 第二个重要极限

```
lim(x→∞) (1 + 1/x)^x = e
```

或等价形式：
```
lim(t→0) (1 + t)^(1/t) = e
```

**推广形式**：若 lim α(x) = 0，则 lim (1 + α(x))^(1/α(x)) = e

### 6.3 例题

**例 12**：求 lim(x→0) sin3x/x

解：= lim(x→0) 3·sin3x/(3x) = 3·lim(x→0) sin3x/(3x) = 3·1 = 3

**例 13**：求 lim(x→0) (1-cosx)/x²

解：利用 1-cosx = 2sin²(x/2)
= lim(x→0) 2sin²(x/2)/x² = lim(x→0) 2·sin²(x/2)/(4·(x/2)²)
= (1/2)·[lim(x→0) sin(x/2)/(x/2)]² = 1/2·1 = 1/2

**例 14**：求 lim(x→∞) (1 + 2/x)^x

解：= lim(x→∞) [(1 + 2/x)^(x/2)]² = e²

**例 15**：求 lim(x→0) (1-3x)^(1/x)

解：= lim(x→0) [(1 + (-3x))^(1/(-3x))]^(-3) = e^(-3)

### 6.4 常见错误

❌ **错误 1**：lim(x→0) sin(1/x)/(1/x) = 1
✅ 正确：当 x → 0 时，1/x → ∞，不是 0，故公式不适用。
实际上：lim(x→0) x·sin(1/x) = 0（有界×无穷小）

❌ **错误 2**：lim(x→0) (1+x)^(1/x²) = e
✅ 正确：注意指数是 1/x² 而非 1/x，应按实际情况变形。

## 第七节 函数的连续性

### 7.1 函数连续的定义

设函数 y = f(x) 在点 x₀ 的某邻域内有定义，若：

```
lim(x→x₀) f(x) = f(x₀)
```

则称函数 f(x) 在点 x₀ **连续**。

**等价定义（增量形式）**：设 Δx = x - x₀，Δy = f(x₀+Δx) - f(x₀)，若：
```
lim(Δx→0) Δy = 0
```

则 f(x) 在 x₀ 连续。

### 7.2 左连续与右连续

- **左连续**：lim(x→x₀⁻) f(x) = f(x₀)
- **右连续**：lim(x→x₀⁺) f(x) = f(x₀)

**定理**：f(x) 在 x₀ 连续 ⇔ f(x) 在 x₀ 既左连续又右连续。

### 7.3 连续函数的运算

1. 连续函数的和、差、积、商（分母不为零）仍是连续函数。
2. 连续函数的复合函数仍是连续函数。
3. 严格单调连续函数的反函数也是严格单调连续的。

### 7.4 初等函数的连续性

一切**基本初等函数**在其定义域内都是连续的。
一切**初等函数**在其**定义区间**内都是连续的。

### 7.5 闭区间上连续函数的性质

**有界性定理**：在闭区间上连续的函数在该区间上一定有界。

**最值定理**：在闭区间上连续的函数在该区间上一定能取得最大值和最小值。

**零点定理**：设 f(x) 在 [a, b] 上连续，且 f(a)·f(b) < 0，则至少存在一点 ξ ∈ (a, b)，使 f(ξ) = 0。

**介值定理**：设 f(x) 在 [a, b] 上连续，f(a) = A，f(b) = B，则对 A 与 B 之间的任意常数 C，至少存在一点 ξ ∈ (a, b)，使 f(ξ) = C。

### 7.6 例题

**例 16**：讨论函数 f(x) = { x², x ≤ 1; x+1, x > 1 } 在 x = 1 处的连续性。

解：
- f(1) = 1² = 1
- 左极限：lim(x→1⁻) f(x) = lim(x→1⁻) x² = 1
- 右极限：lim(x→1⁺) f(x) = lim(x→1⁺) (x+1) = 2

因为左右极限不相等，所以 f(x) 在 x=1 处不连续（右不连续）。

**例 17**：证明方程 x⁵ - 3x = 1 在区间 (1, 2) 内至少有一个实根。

证明：设 f(x) = x⁵ - 3x - 1，则 f(x) 在 [1, 2] 上连续。
f(1) = 1 - 3 - 1 = -3 < 0
f(2) = 32 - 6 - 1 = 25 > 0

由零点定理，存在 ξ ∈ (1, 2)，使 f(ξ) = 0，即 ξ⁵ - 3ξ = 1。
故原方程在 (1, 2) 内至少有一个实根。

### 7.7 常见错误

❌ **错误 1**：认为初等函数在其定义域内都连续。
✅ 正确：初等函数在其**定义区间**内连续（定义域可能有孤立点）。

❌ **错误 2**：对开区间上的连续函数使用最值定理。
✅ 正确：必须是**闭区间**上的连续函数才能使用这些定理。

## 第八节 函数的间断点

### 8.1 间断点的定义

若函数 f(x) 在点 x₀ 的某去心邻域内有定义，但在 x₀ 处不连续，则称 f(x) 在 x₀ 处**间断**，称 x₀ 为 f(x) 的**间断点**。

f(x) 在 x₀ 处不连续的三种情形：
1. f(x₀) 不存在；
2. lim(x→x₀) f(x) 不存在；
3. f(x₀) 存在，极限也存在，但两者不相等。

### 8.2 间断点的分类

**第一类间断点**：左右极限都存在。
- **可去间断点**：左右极限相等但不等于 f(x₀)，或 f(x₀) 无定义。
- **跳跃间断点**：左右极限都存在但不相等。

**第二类间断点**：左右极限至少有一个不存在。
- **无穷间断点**：极限为 ∞。
- **振荡间断点**：极限振荡不存在。

### 8.3 例题

**例 18**：求 f(x) = (x²-1)/(x²-3x+2) 的间断点并分类。

解：分母为 0 时，x²-3x+2 = 0，即 (x-1)(x-2) = 0，得 x = 1 或 x = 2。

- x = 1：
  lim(x→1) f(x) = lim(x→1) (x-1)(x+1)/[(x-1)(x-2)] = lim(x→1) (x+1)/(x-2) = -2
  左右极限存在且相等，故 x = 1 是**可去间断点**。

- x = 2：
  lim(x→2) f(x) = lim(x→2) (x+1)/(x-2) = ∞
  故 x = 2 是**无穷间断点**（第二类）。
