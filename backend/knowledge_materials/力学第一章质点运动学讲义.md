# 力学第一章：质点运动学讲义

## 第一节 参考系与坐标系

### 1.1 机械运动与质点

**机械运动**：一个物体相对于另一个物体的位置随时间变化，或者物体内部各部分之间的相对位置随时间变化，是自然界中最简单、最基本的运动形态。

**质点**：在研究物体的运动时，如果物体的**形状和大小**对我们所研究的问题不起作用或所起的作用可以忽略不计，我们就可以把物体简化为一个只有**质量**而没有形状和大小的理想模型，称为**质点**。

质点是一个**理想化的物理模型**，现实中并不存在。判断能否将物体视为质点的标准：
- 研究地球绕太阳公转 → 地球大小比轨道半径小得多 → 可以视为质点
- 研究地球自转 → 地球的形状大小不能忽略 → 不能视为质点
- 研究火车从北京到上海的时间 → 可视为质点
- 研究火车通过桥梁的时间 → 必须考虑火车长度 → 不能视为质点

### 1.2 参考系（Reference Frame）

宇宙中的一切物体都在永不停息地运动着，运动是**绝对的**，而静止是**相对的**。要描述一个物体的运动，首先必须选定其他物体作为**参考标准**，这个被选作参考、假定为不动的物体叫做**参考系**（参照物）。

- 选择不同的参考系，对同一物体运动的描述可能不同。
- 参考系的选取是任意的，通常以**解决问题方便**为原则。
- 讨论地面物体的运动时，通常选取**地面**或相对地面静止的物体作为参考系。

**示例**：在匀速行驶的汽车中，乘客相对于汽车是静止的，但相对于地面是运动的。

### 1.3 坐标系（Coordinate System）

为了**定量地描述**物体的位置及其变化，需要在参考系上建立适当的坐标系。

常用的坐标系：

| 坐标系类型 | 适用场景 | 坐标表示 |
|-----------|---------|---------|
| 直角坐标系（笛卡尔坐标系） | 平面或空间中一般运动 | (x, y, z) |
| 极坐标系 | 平面圆周运动、径向运动 | (ρ, θ) |
| 自然坐标系 | 已知轨迹的曲线运动 | (s)，沿轨道的弧长 |

#### 直角坐标系

三维直角坐标系由三条互相垂直的坐标轴组成：
- x 轴（横轴）
- y 轴（纵轴）
- z 轴（竖轴）

三轴交点称为**原点 O**。三轴的正方向遵循**右手螺旋定则**：右手四指从 x 轴正向逆时针转到 y 轴正向时，大拇指的指向就是 z 轴的正向。

空间中任意一点 P 的位置可用坐标 (x, y, z) 表示。

## 第二节 位置矢量与位移

### 2.1 位置矢量（位矢）

在选定的参考系中，为了定量描述质点的位置，我们从坐标系的**原点 O** 向质点所在的位置 P 作一条有向线段，记作矢量 **r**，称为质点的**位置矢量**，简称**位矢**。

在直角坐标系中，位置矢量可以分解为：

```
r = x i + y j + z k
```

其中：
- **i, j, k** 分别是沿 x、y、z 轴正方向的**单位矢量**（大小为 1 的矢量）
- x、y、z 是 P 点的三个坐标，也是位矢在三个坐标轴上的**投影**

位矢的**大小**（质点到原点的距离）：
```
|r| = r = √(x² + y² + z²)
```

位矢的**方向**可用三个方向余弦表示：
```
cos α = x / r
cos β = y / r
cos γ = z / r
```
其中 α、β、γ 分别是位矢与 x、y、z 轴正方向的夹角，满足 cos²α + cos²β + cos²γ = 1。

### 2.2 运动方程（运动函数）

当质点运动时，它的位置随时间变化，位矢 r 是时间 t 的函数：

```
r(t) = x(t) i + y(t) j + z(t) k
```

这个函数叫做质点的**运动方程**（或运动函数）。

在直角坐标系中的**分量形式**：
```
x = x(t)
y = y(t)
z = z(t)
```

**轨迹**：质点在运动过程中所经过的路径。将运动方程中的参数 t 消去，可得到轨迹方程。

**示例**：
```
x = R cos ωt
y = R sin ωt
消去 t 得：x² + y² = R²  （圆心在原点、半径为 R 的圆）
```

### 2.3 位移（Displacement）

设质点沿曲线运动，时刻 t₁ 在 A 点，位矢为 r₁；时刻 t₂ 到达 B 点，位矢为 r₂。

从**初位置 A** 指向**末位置 B** 的有向线段 AB 称为质点在时间间隔 Δt = t₂ - t₁ 内的**位移**，记作 Δr：

```
Δr = r₂ - r₁
```

在直角坐标系中的分量形式：
```
Δr = (x₂ - x₁) i + (y₂ - y₁) j + (z₂ - z₁) k
    = Δx i + Δy j + Δz k
```

位移的**大小**：
```
|Δr| = √(Δx² + Δy² + Δz²)
```

### 2.4 位移和路程的区别

| 物理量 | 位移 Δr | 路程 s |
|-------|---------|--------|
| 性质 | 矢量（有大小、有方向） | 标量（只有大小） |
| 定义 | 从初位置到末位置的有向线段 | 质点实际运动轨迹的长度 |
| 关系 | 单向直线运动时，\|Δr\| = s；一般曲线运动时，\|Δr\| < s；总是 \|Δr\| ≤ s |

**典型例题 1**：一质点沿半径为 R 的圆周运动一周，求位移和路程。

解：
- 位移：初末位置相同，Δr = 0，|Δr| = 0
- 路程：等于圆周长，s = 2πR

**典型例题 2**：某人向东走 30m，又向北走 40m，求位移和路程。

解：
- 路程：s = 30m + 40m = 70m
- 位移大小：|Δr| = √(30² + 40²) = 50m
- 位移方向：东偏北 θ，tanθ = 40/30 = 4/3，θ ≈ 53.1°

### 2.5 |Δr| 与 Δr 的区别 ⚠️

- **|Δr|** = |r₂ - r₁|：位移矢量的**大小**（初末位置之间的直线距离）
- **Δr** = |r₂| - |r₁|：位矢**大小的增量**（末位置到原点的距离减初位置到原点的距离）

一般情况下 |Δr| ≠ Δr。

**反例**：质点作匀速圆周运动半周：
- |r₁| = |r₂| = R → Δr = 0
- |Δr| = 2R（直径）
- 此时 |Δr| ≠ Δr

## 第三节 速度与加速度

### 3.1 平均速度

设质点在时间 Δt 内的位移为 Δr，则**平均速度**定义为：

```
v̄ = Δr / Δt
```

- 平均速度是**矢量**，方向与位移 Δr 相同。
- 平均速度的大小和方向与所取的时间间隔有关，因此必须指明是哪一段时间内的平均速度。

**平均速率**（标量）：质点在 Δt 时间内通过的路程 Δs 与时间的比值：
```
v̄_rate = Δs / Δt
```

注意：平均速率一般不等于平均速度的大小。只有单向直线运动中两者才相等。

### 3.2 瞬时速度（速度）

当 Δt → 0 时，平均速度的极限称为质点在时刻 t 的**瞬时速度**，简称**速度**：

```
v = lim(Δt→0) Δr/Δt = dr/dt
```

速度是位置矢量对时间的**一阶导数**。

- 速度是**矢量**，方向沿轨道的**切线方向**，指向质点前进的一侧。
- 速度的**直角坐标分量形式**：
  ```
  v = v_x i + v_y j + v_z k
  其中
  v_x = dx/dt,  v_y = dy/dt,  v_z = dz/dt
  ```
- 速度的大小（速率）：
  ```
  v = |v| = √(v_x² + v_y² + v_z²)
  ```

### 3.3 平均加速度与瞬时加速度

速度是矢量，速度的**变化**包括大小变化和方向变化。

设质点在 t 时刻的速度为 v₁，在 t+Δt 时刻的速度为 v₂，则速度增量为：
```
Δv = v₂ - v₁
```

**平均加速度**：
```
ā = Δv / Δt
```

平均加速度的方向与速度增量 Δv 的方向相同。

**瞬时加速度（加速度）**：当 Δt → 0 时，平均加速度的极限：
```
a = lim(Δt→0) Δv/Δt = dv/dt = d²r/dt²
```

加速度是速度对时间的**一阶导数**，或位矢对时间的**二阶导数**。

- 加速度是**矢量**，方向与 Δv 的极限方向相同，一般与速度 v 的方向**不同**。
- 直角坐标分量形式：
  ```
  a = a_x i + a_y j + a_z k
  其中
  a_x = dv_x/dt = d²x/dt²
  a_y = dv_y/dt = d²y/dt²
  a_z = dv_z/dt = d²z/dt²
  ```
- 加速度的大小：
  ```
  a = |a| = √(a_x² + a_y² + a_z²)
  ```

### 3.4 加速度方向与运动的关系

| 加速度与速度方向关系 | 运动效果 |
|-------------------|---------|
| 同向（夹角 0°） | 速率增大（加速直线运动） |
| 反向（夹角 180°） | 速率减小（减速直线运动） |
| 垂直（夹角 90°） | 速率不变，方向改变（匀速圆周运动） |
| 锐角夹角 | 速率增大，方向改变（加速曲线运动） |
| 钝角夹角 | 速率减小，方向改变（减速曲线运动） |

## 第四节 匀变速直线运动

### 4.1 匀变速直线运动定义

物体在一条直线上运动，如果在**相等的时间内速度的变化量相等**，即**加速度 a 恒定不变**，则称为**匀变速直线运动**。

### 4.2 基本公式（四个核心公式）

设初始时刻 t = 0 时，初速度为 v₀，位置坐标为 x₀；任意时刻 t 时，速度为 v，位置为 x，位移为 s = x - x₀。

| 公式 | 表达式 | 不含的物理量 |
|-----|-------|------------|
| 速度公式 | v = v₀ + at | 位移 s |
| 位移公式 | s = v₀t + ½at² | 末速度 v |
| 速度位移关系 | v² - v₀² = 2as | 时间 t |
| 平均速度公式 | s = (v₀ + v)t/2 | 加速度 a |

### 4.3 公式推导

**速度公式推导**：
由加速度定义 a = dv/dt，得 dv = a·dt。
两边积分，初始条件 t=0 时 v=v₀：
```
∫(v₀到v) dv = ∫(0到t) a·dt
v - v₀ = at
故 v = v₀ + at
```

**位移公式推导**：
由 v = dx/dt，得 dx = v·dt = (v₀ + at) dt。
两边积分，初始条件 t=0 时 x=x₀：
```
∫(x₀到x) dx = ∫(0到t) (v₀ + at) dt
x - x₀ = v₀t + ½at²
故 s = v₀t + ½at²
```

**速度位移公式推导**：
由 v = v₀ + at 得 t = (v-v₀)/a，代入位移公式：
```
s = v₀·(v-v₀)/a + ½a·((v-v₀)/a)²
整理得 v² - v₀² = 2as
```

### 4.4 典型例题

**例题 1**：一辆汽车以 20 m/s 的速度匀速行驶，司机看到前方红灯后开始制动，加速度大小为 5 m/s²。求：
（1）汽车制动后 2 s 末的速度和 2 s 内的位移；
（2）汽车制动后 5 s 末的速度和 5 s 内的位移。

解：已知 v₀ = 20 m/s，a = -5 m/s²（减速，与运动方向相反）。

（1）先判断汽车停下的时间：
由 v = v₀ + at，停车时 v = 0，得 t₀ = -v₀/a = -20/(-5) = 4 s

t₁ = 2 s < t₀，汽车尚未停止：
v₁ = v₀ + at₁ = 20 + (-5)×2 = 10 m/s
s₁ = v₀t₁ + ½at₁² = 20×2 + ½×(-5)×4 = 40 - 10 = 30 m

（2）t₂ = 5 s > t₀ = 4 s，汽车在 4 s 时已停下，之后保持静止：
v₅ = 0
s₅ = 4 s 内的位移 = v₀t₀ + ½at₀² = 20×4 + ½×(-5)×16 = 80 - 40 = 40 m
或用 v²-v₀²=2as：0 - 400 = 2×(-5)×s → s = 40 m

> 注意：刹车问题一定要先判断车何时停下！

**例题 2**：自由落体运动。物体从高度 h = 45 m 处自由落下（g = 10 m/s²），求落地时的速度和下落时间。

解：自由落体是初速度 v₀ = 0、加速度 a = g 的匀加速直线运动。

由 v² - v₀² = 2as：
v² = 2gh = 2 × 10 × 45 = 900
v = 30 m/s（取正）

由 v = v₀ + at：
t = v/g = 30/10 = 3 s

## 第五节 抛体运动

### 5.1 运动的叠加原理（运动的独立性原理）

任何一个复杂的曲线运动都可以**分解为**几个各自独立进行的简单的**分运动**。

抛体运动是典型的二维运动，可分解为：
- **水平方向**：匀速直线运动（加速度为 0）
- **竖直方向**：匀变速直线运动（加速度为 g，重力加速度）

### 5.2 平抛运动

将物体以一定的初速度 v₀ 沿**水平方向**抛出，只受重力作用的运动。

**建立坐标系**：以抛出点为原点，水平向右为 x 轴，竖直向下为 y 轴。

**运动方程**：
```
x方向（匀速）：  v_x = v₀        x = v₀t
y方向（自由落体）：v_y = gt       y = ½gt²
```

**合速度**：
```
大小：v = √(v_x² + v_y²) = √(v₀² + (gt)²)
方向：与水平方向夹角 θ，tanθ = v_y/v_x = gt/v₀
```

**轨迹方程**：消去 t，得 y = gx² / (2v₀²) → **抛物线**

**飞行时间 T**：由下落高度 h 决定（与初速度无关！）
```
h = ½gT²   →   T = √(2h/g)
```

**水平射程 R**：
```
R = v₀T = v₀√(2h/g)
```

**例题 3**：在 45 m 高的阳台上以 10 m/s 的水平初速度抛出一个小球，求（g=10m/s²）：
（1）小球落地的时间；（2）落地点到抛出点的水平距离；（3）落地时的速度。

解：
（1）T = √(2h/g) = √(2×45/10) = √9 = 3 s
（2）R = v₀T = 10 × 3 = 30 m
（3）v_x = v₀ = 10 m/s，v_y = gT = 10 × 3 = 30 m/s
     合速度 v = √(10² + 30²) = √1000 ≈ 31.6 m/s
     与水平方向夹角 θ = arctan(30/10) ≈ 71.6°

### 5.3 斜抛运动

将物体以初速度 v₀ 沿与水平方向成 θ 角斜向上抛出。

**分速度**：
```
v₀x = v₀ cosθ     v₀y = v₀ sinθ
```

**运动方程**（以向上为 y 轴正方向，重力加速度向下，为负）：
```
x方向（匀速）：  v_x = v₀cosθ       x = v₀cosθ · t
y方向（竖直上抛）：v_y = v₀sinθ - gt   y = v₀sinθ · t - ½gt²
```

**几个特征量**：

1. **上升到最高点的时间**（v_y = 0 时）：
   ```
   t_h = v₀sinθ / g
   ```

2. **最大高度（射高）**：
   ```
   H = (v₀sinθ)² / (2g)
   ```

3. **飞行总时间**（落回原高度 y = 0 时）：
   ```
   T = 2t_h = 2v₀sinθ / g
   ```

4. **水平射程 R**：
   ```
   R = v₀cosθ · T = v₀²·sin2θ / g
   ```

**重要结论**：当 v₀ 一定时，sin2θ = 1 即 θ = 45° 时，射程 R 最大。

## 第六节 圆周运动

### 6.1 描述圆周运动的物理量

#### 线速度 v

质点沿圆周运动的瞬时速度，方向沿圆周切线方向。
- 大小：通过的弧长 Δs 与时间 Δt 之比，v = ds/dt
- 单位：m/s

#### 角速度 ω

连接质点和圆心的半径转过的角度 Δθ 与所用时间 Δt 之比：
```
ω = dθ/dt
```
- 单位：rad/s（弧度/秒）
- 匀速圆周运动的角速度是**恒定值**

#### 周期 T

质点沿圆周运动一周所需的时间，单位：s。

#### 转速 n

单位时间内质点转过的圈数，单位：r/s（转/秒）或 r/min（转/分）。

#### 各量之间的关系

```
ω = 2π / T = 2πn
v = ωR = 2πR / T = 2πnR
```

（R 为圆周运动的半径）

### 6.2 匀速圆周运动的加速度

匀速圆周运动的**速度大小不变**，但**方向时刻在变**，因此存在加速度。

#### 向心加速度（法向加速度）

```
大小：a_n = v²/R = ω²R
方向：始终指向圆心（与速度方向垂直）
作用：只改变速度的方向，不改变速度的大小
```

### 6.3 变速圆周运动的加速度

变速圆周运动的速度大小和方向都在变化，因此加速度可以分解为两个互相垂直的分量：

| 分量 | 名称 | 大小 | 方向 | 作用 |
|-----|------|------|------|------|
| a_n | 法向（向心）加速度 | v²/R | 指向圆心 | 改变速度方向 |
| a_τ | 切向加速度 | dv/dt | 沿切线方向 | 改变速度大小 |

**总加速度**：
```
大小：a = √(a_n² + a_τ²)
方向：与切线方向夹角 φ，tanφ = a_n / a_τ
```

### 6.4 典型例题

**例题 4**：地球绕太阳公转可近似看作匀速圆周运动，轨道半径约为 R = 1.5×10¹¹ m，周期 T = 365 天。求地球公转的角速度、线速度和向心加速度。

解：
T = 365 × 24 × 3600 ≈ 3.15×10⁷ s

角速度：
ω = 2π/T ≈ 2×3.14/(3.15×10⁷) ≈ 2.0×10⁻⁷ rad/s

线速度：
v = ωR ≈ 2.0×10⁻⁷ × 1.5×10¹¹ = 3.0×10⁴ m/s = 30 km/s

向心加速度：
a_n = v²/R ≈ (9.0×10⁸)/(1.5×10¹¹) ≈ 6.0×10⁻³ m/s²

**例题 5**：一质点沿半径为 R = 0.1 m 的圆周运动，其运动方程为 θ = 2 + 4t³（θ 以 rad 计，t 以 s 计）。求 t = 2 s 时的切向加速度、法向加速度和总加速度。

解：
角速度：ω = dθ/dt = 12t²
线速度：v = ωR = 12t² × 0.1 = 1.2t²

切向加速度：
a_τ = dv/dt = 2.4t
t = 2 s 时，a_τ = 2.4 × 2 = 4.8 m/s²

法向加速度：
a_n = v²/R = (1.2t²)² / 0.1 = 14.4t⁴
t = 2 s 时，a_n = 14.4 × 16 = 230.4 m/s²

总加速度：
a = √(a_n² + a_τ²) = √(230.4² + 4.8²) ≈ 230.5 m/s²
