# 高等数学常见习题与易错点汇编

## 第一部分：极限计算中的常见错误

### 错误类型一：等价无穷小的误用

#### 典型错误说明

等价无穷小替换是计算极限的常用方法，但**只能在乘除运算中替换**，在加减运算中随意替换会导致错误。

正确原则：设 α ~ α'，β ~ β'（同一极限过程），则：
- 在 lim α·f(x) 中，可替换为 lim α'·f(x)
- 在 lim α/f(x) 中，可替换为 lim α'/f(x)
- 在 lim (α ± β) 中，一般**不能直接替换** α 和 β

#### 常见等价无穷小（x → 0 时）

| 等价关系 | 备注 |
|---------|------|
| sinx ~ x | arcsinx ~ x |
| tanx ~ x | arctanx ~ x |
| 1-cosx ~ x²/2 | |
| ln(1+x) ~ x | log_a(1+x) ~ x/lna |
| e^x - 1 ~ x | a^x - 1 ~ xlna |
| (1+x)^α - 1 ~ αx | α ≠ 0 |

#### 例题 1：错误解法 vs 正确解法

**题目**：求 lim(x→0) (tanx - sinx) / x³

❌ **错误解法**：
```
lim(x→0) (tanx - sinx) / x³
= lim(x→0) (x - x) / x³     （错误：tanx ~ x, sinx ~ x 直接在减法中替换）
= lim(x→0) 0 / x³
= 0
```

✅ **正确解法**：
```
lim(x→0) (tanx - sinx) / x³
= lim(x→0) tanx(1 - cosx) / x³
= lim(x→0) [x · (x²/2)] / x³     （乘除运算中可以替换：tanx ~ x, 1-cosx ~ x²/2）
= lim(x→0) (x³/2) / x³
= 1/2
```

#### 例题 2：加减中何时可以替换？

加减替换的**充分条件**：若 α ~ α'，β ~ β'，且 lim α/β = c ≠ -1，则：
- α + β ~ α' + β'

若 lim α/β = c ≠ 1，则：
- α - β ~ α' - β'

**题目**：求 lim(x→0) (sin2x + tan3x) / x

验证：sin2x ~ 2x，tan3x ~ 3x，lim(2x/3x) = 2/3 ≠ -1
∴ sin2x + tan3x ~ 2x + 3x = 5x

极限 = lim(x→0) 5x/x = 5

#### 练习题 1-1

求下列极限（注意等价无穷小的使用条件）：
1. lim(x→0) (e^x - 1 - x) / x²
2. lim(x→0) (x - sinx) / x³
3. lim(x→0) (1 - cosx·cos2x) / x²

**参考答案**：
1. 1/2（用泰勒展开或洛必达）
2. 1/6（用泰勒展开：sinx = x - x³/6 + ...）
3. 5/2（1 - cosx·cos2x = 1 - cosx + cosx(1 - cos2x)）

### 错误类型二：洛必达法则条件不满足

#### 洛必达法则使用条件

对于 0/0 或 ∞/∞ 型未定式，若满足：
1. lim f(x) = lim g(x) = 0（或同为 ∞）
2. f(x) 和 g(x) 在 x₀ 的去心邻域内可导，且 g'(x) ≠ 0
3. lim f'(x)/g'(x) 存在（或为 ∞）

则 lim f(x)/g(x) = lim f'(x)/g'(x)

**常见违反情形**：
- 不是 0/0 或 ∞/∞ 型就使用
- 求导后极限不存在（振荡），误认为原极限不存在
- 循环使用导致错误

#### 例题 3：非未定式误用

**题目**：求 lim(x→0) (x + 1) / (x + 2)

❌ **错误解法**：
```
lim(x→0) (x+1)/(x+2) = lim(x→0) 1/1 = 1     （错误：不是 0/0 或 ∞/∞ 型）
```

✅ **正确解法**：
```
lim(x→0) (x+1)/(x+2) = (0+1)/(0+2) = 1/2     （直接代入）
```

#### 例题 4：求导后极限振荡不存在

**题目**：求 lim(x→∞) (x + sinx) / x

❌ **错误解法**：
```
lim(x→∞) (x+sinx)/x = lim(x→∞) (1+cosx)/1   （用洛必达）
lim(1+cosx) 振荡不存在，故原极限不存在       （错误：法则条件3不满足）
```

✅ **正确解法**：
```
lim(x→∞) (x+sinx)/x = lim(x→∞) (1 + sinx/x) = 1 + 0 = 1
```

> 注意：洛必达的条件是**充分条件**而非必要条件。当 lim f'/g' 不存在（振荡）时，原极限可能仍存在。

#### 例题 5：循环陷阱

**题目**：求 lim(x→+∞) e^x / e^x

❌ **错误解法**：
```
lim e^x/e^x = lim e^x/e^x = ...（无限循环）
```

✅ **正确解法**：
```
lim(x→+∞) e^x/e^x = lim 1 = 1
```

#### 练习题 1-2

判断下列洛必达使用是否正确，错误的请改正：
1. lim(x→1) (x³-3x+2)/(2x³-x²-4x+3) = lim(3x²-3)/(6x²-2x-4) = lim(6x)/(12x-2) = 6/10 = 3/5
2. lim(x→∞) (x+sinx)/x = lim(1+cosx)/1 = 不存在
3. lim(x→0) (x²sin1/x)/sinx = lim(2x·sin1/x - cos1/x)/cosx = 不存在

**参考答案**：
1. 正确（连续两次都是 0/0 型）
2. 错误，答案 = 1（见例题 4）
3. 错误，应改为 = lim(x·sin1/x · x/sinx) = 0·1 = 0

### 错误类型三：1^∞ 型极限公式误用

#### 正确公式

第二个重要极限：lim(1 + u)^v = e^(lim v·u)，其中 lim u = 0, lim v = ∞。

或者写成：lim f(x)^g(x)，当 lim f(x) = 1, lim g(x) = ∞ 时，
= e^[lim g(x)(f(x)-1)]

#### 例题 6：公式套用错误

**题目**：求 lim(x→0) (cosx)^(1/x²)

❌ **错误解法**：
```
lim(cosx)^(1/x²) = lim(1 + cosx - 1)^(1/x²)
= e^[lim (1/x²)]                    （错误：漏乘 (cosx-1)）
```

✅ **正确解法**：
```
lim(cosx)^(1/x²) = lim[1 + (cosx-1)]^(1/x²)
= e^[lim (cosx-1)/x²]               （指数为 lim v·u = lim 1/x²·(cosx-1)）
= e^[lim (-x²/2)/x²]                （cosx-1 ~ -x²/2）
= e^(-1/2)
```

## 第二部分：连续性判断易错题

### 典型例题精讲

#### 例题 7：分段函数在分段点的连续性

**题目**：讨论 f(x) 在 x = 0 处的连续性
```
f(x) = { (e^(x²) - 1) / x²,  x ≠ 0
       { a,                  x = 0
```
问 a 取何值时，f(x) 在 x = 0 处连续？

解：连续性条件：lim(x→0) f(x) = f(0) = a

计算极限：
lim(x→0) (e^(x²) - 1) / x²
= lim(x→0) x² / x²              （e^(x²) - 1 ~ x²）
= 1

所以当 a = 1 时，f(x) 在 x = 0 处连续。

#### 例题 8：含绝对值函数的连续性

**题目**：讨论 f(x) = x·|x|/(x²+1) 的连续性

解：先去绝对值改写为分段函数：
```
f(x) = { -x²/(x²+1),  x < 0
       { 0,            x = 0
       { x²/(x²+1),   x > 0
```

- 当 x < 0 时，f(x) = -x²/(x²+1) 是初等函数，连续；
- 当 x > 0 时，f(x) = x²/(x²+1) 是初等函数，连续；
- 当 x = 0 时：
  - lim(x→0⁻) f(x) = lim -x²/(x²+1) = 0
  - lim(x→0⁺) f(x) = lim x²/(x²+1) = 0
  - f(0) = 0
  故 x = 0 处也连续。

综上，f(x) 在整个实数域 R 上连续。

#### 例题 9：复合函数的连续性陷阱

**题目**：判断正误：若 g(x) 在 x₀ 连续，f(u) 在 u₀ = g(x₀) 连续，则 f(g(x)) 在 x₀ 连续。

✅ **正确**：这是复合函数的连续性定理。

**变化题**：若 lim(x→x₀) g(x) = u₀，且 f(u) 在 u₀ 连续，则 lim(x→x₀) f(g(x)) = f(u₀) 是否成立？

✅ **正确**：连续性条件比极限条件强，不需要 g(x) ≠ u₀ 的条件。

#### 练习题 2-1

1. 设 f(x) = { sin2x/x, x < 0; 3x² - 2x + k, x ≥ 0 }，问 k 为何值时，函数在 x = 0 处连续？
2. 讨论 f(x) = lim(n→∞) (1 - x^(2n))/(1 + x^(2n)) · x 的连续性，并画出草图。
3. 若 f(x) 在 x = 0 处连续，且对任意 x₁, x₂ 有 f(x₁+x₂) = f(x₁) + f(x₂)，证明 f(x) 在 R 上连续。

**参考答案**：
1. k = 2（左极限 = 2，右极限 = k）
2. 提示：分 |x| < 1, |x| = 1, |x| > 1 三种情况讨论。
   f(x) = { x,    |x| < 1
          { 0,    |x| = 1
          { -x,   |x| > 1
   间断点：x = ±1，都是跳跃间断点。
3. 提示：先由 f(0+0) = f(0)+f(0) 得 f(0) = 0，再利用 lim(Δx→0) f(x+Δx) = f(x) + lim f(Δx) = f(x)+f(0) = f(x)。

## 第三部分：间断点分类练习

### 判断步骤

1. 找出函数无定义的点（分母为 0、对数真数为 0 等）和分段函数的分段点；
2. 对每一个可疑点 x₀，计算左右极限；
3. 根据极限情况分类：
   - 左右极限都存在 → 第一类（相等则可去，不等则跳跃）
   - 至少一个不存在 → 第二类（无穷或振荡）

### 例题 10：有理函数的间断点

**题目**：求 f(x) = x / tanx 的间断点并分类。

解：tanx 无定义或为 0 的点即可疑点：
- tanx 无定义：x = π/2 + nπ（n ∈ Z）
- tanx = 0：x = nπ（n ∈ Z）

分类讨论：

**x = 0（n = 0 时 tanx = 0）**：
lim(x→0) x/tanx = lim(x→0) x/x = 1
左右极限存在且相等 → **可去间断点**

**x = nπ（n ≠ 0）**：
lim(x→nπ) x/tanx = ∞（分子不为 0，分母 → 0）
→ **无穷间断点**

**x = π/2 + nπ**：
lim(x→π/2+nπ) x/tanx = 0（分子有限，分母 → ∞）
左右极限存在且相等 → **可去间断点**

### 例题 11：振荡间断点经典例子

**题目**：指出 f(x) = sin(1/x) 的间断点及类型。

解：x = 0 处无定义。
当 x → 0 时，1/x → ∞，sin(1/x) 在 [-1, 1] 之间振荡，极限不存在。
故 x = 0 是 **振荡间断点**（第二类）。

注意：这是振荡的例子，但函数本身是有界的。

### 例题 12：含取整函数的间断点

**题目**：讨论 f(x) = x - [x] 的间断点（[x] 为取整函数）。

解：设 n 为任意整数。
当 n ≤ x < n+1 时，[x] = n，故 f(x) = x - n。

- 在每个开区间 (n, n+1) 内，f(x) = x - n 是线性函数，连续。
- 在每个整数点 x = n 处：
  - f(n) = n - [n] = 0
  - lim(x→n⁻) f(x) = lim(x→n⁻) (x - (n-1)) = n - (n-1) = 1
  - lim(x→n⁺) f(x) = lim(x→n⁺) (x - n) = 0
  右极限等于 f(n)，左极限不等于 → **跳跃间断点**（右连续）

跳跃度 = 右极限 - 左极限 = 0 - 1 = -1

### 练习题 3-1

指出下列函数的间断点并分类：
1. f(x) = x(x-π) / (sinx)
2. f(x) = (x² - x) / (|x|(x² - 1))
3. f(x) = arctan(1/x)
4. f(x) = 1 / ln|x|

**参考答案**：
1. x = 0：可去；x = π：可去；x = kπ（k ≠ 0, 1）：无穷
2. x = 0：跳跃；x = 1：可去；x = -1：无穷
3. x = 0：跳跃（左极限 -π/2，右极限 π/2）
4. x = 0：可去；x = ±1：无穷；注意 |x|=1 时分母为 0

## 第四部分：综合提高题

### 习题 1

设 lim(x→0) f(x)/x = A（常数），求 lim(x→0) (√(1+f(x)) - 1) / x。

**解答**：
由已知，lim(x→0) f(x)/x = A，故 f(x) ~ Ax (x→0)，即 f(x) → 0。

分子有理化：
lim [√(1+f(x)) - 1] / x
= lim [f(x)] / [x(√(1+f(x)) + 1)]
= lim [f(x)/x] · lim [1/(√(1+f(x)) + 1)]
= A · [1/(1+1)]
= A/2

### 习题 2

求常数 a 和 b，使 lim(x→+∞) (√(x² - x + 1) - ax - b) = 0。

**解答**：
这是 ∞ - ∞ 型，有理化：
√(x² - x + 1) - ax - b
= (x² - x + 1 - (ax+b)²) / (√(x² - x + 1) + ax + b)
= [(1-a²)x² - (1+2ab)x + (1-b²)] / (√(x² - x + 1) + ax + b)

分子分母同除以 x：
= [(1-a²)x - (1+2ab) + (1-b²)/x] / (√(1 - 1/x + 1/x²) + a + b/x)

分母极限 = 1 + a，要使整体极限 = 0，必须：
1. 分子最高次项系数 = 0：1 - a² = 0
2. 分子常数项极限 = 0：-(1 + 2ab) = 0

由 1：a = ±1
但 a = -1 时分母极限 = 1 - 1 = 0，舍去，故 a = 1
代入 2：-(1 + 2b) = 0，得 b = -1/2

综上：a = 1，b = -1/2

### 习题 3：零点定理应用

设 f(x) 在 [0, 1] 上连续，且 0 ≤ f(x) ≤ 1，证明存在 ξ ∈ [0, 1]，使得 f(ξ) = ξ。

（这样的 ξ 称为 f 的不动点。）

**证明**：

构造辅助函数 g(x) = f(x) - x。

由 f(x) 的连续性，g(x) 在 [0, 1] 上也连续。

计算端点值：
g(0) = f(0) - 0 = f(0) ≥ 0
g(1) = f(1) - 1 ≤ 0

分情况讨论：
1. 若 g(0) = 0，则 ξ = 0，有 f(0) = 0，得证。
2. 若 g(1) = 0，则 ξ = 1，有 f(1) = 1，得证。
3. 若 g(0) > 0 且 g(1) < 0，则 g(0)·g(1) < 0。
   由零点定理，存在 ξ ∈ (0, 1)，使得 g(ξ) = 0，即 f(ξ) - ξ = 0，f(ξ) = ξ。

综上，存在 ξ ∈ [0, 1]，使得 f(ξ) = ξ。
