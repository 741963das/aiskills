# 思政课常见论述题答题思路

## 第一章 论述题答题总论

### 1.1 思政课论述题的特点

大学思政课（"思想道德与法治""毛泽东思想和中国特色社会主义理论体系概论""马克思主义基本原理""中国近现代史纲要"）的论述题，和中学政治主观题有相同之处，也有更高要求：

| 特点 | 说明 |
|-----|------|
| **理论性强** | 必须运用马克思主义立场、观点、方法，不能像写散文一样空谈感想 |
| **现实性强** | 往往结合当前社会热点、时代背景（新时代、中国式现代化、中国梦、青年责任等） |
| **逻辑严密** | 观点鲜明、论据充分、层次清晰、结构完整 |
| **立场正确** | 必须坚持四项基本原则，政治方向不能错——这是底线 |

### 1.2 通用答题框架："是什么 — 为什么 — 怎么办"三段式

这是最经典、最通用、最不容易失分的答题结构。无论什么题目，都可以按这个框架展开：

```
┌──────────────────────────────────────────────────────┐
│  第一段：是什么（提出观点 + 阐释概念）                   │
│  · 开门见山，表明你对问题的总体立场和核心观点             │
│  · 阐释题目中涉及的核心概念的定义、内涵、特征             │
│  · 字数：约占总字数 20%                                  │
├──────────────────────────────────────────────────────┤
│  第二段：为什么（分析论证 + 理论依据 + 联系实际）         │
│  · 分 2~3 个论点/角度展开分析论证                        │
│  · 每个论点都要有理论依据（教材中的原理、名言）           │
│  · 每个论点都要尽量联系实际（案例、数据、时代背景）        │
│  · 这是论述题的主体部分，字数约占总字数 60%              │
├──────────────────────────────────────────────────────┤
│  第三段：怎么办（做法/启示/总结升华）                    │
│  · 根据前面的分析，提出应采取的态度、做法、路径           │
│  · 特别是"当代青年应该怎么做"——几乎所有题都要落到青年身上  │
│  · 最后一句总结升华，呼应开头观点，落脚到时代/国家/青年    │
│  · 字数：约占总字数 20%                                  │
└──────────────────────────────────────────────────────┘
```

### 1.3 评分要点（老师怎么打分）

老师批改论述题时，一般看这几个方面：

| 评分维度 | 分值占比 | 得分关键 |
|---------|---------|---------|
| **观点正确、立场鲜明** | 30% | 政治方向不能错；核心观点要在开头明确亮出来，不能绕半天不知所云 |
| **理论运用准确** | 30% | 能正确运用教材上学过的原理、概念来分析，不是自己瞎编 |
| **论述充分、逻辑清晰** | 20% | 分点论述、层层递进；论点 + 论据 + 论证链条完整 |
| **联系实际、内容充实** | 15% | 不是空谈理论，能结合案例、数据、时代背景、社会实际 |
| **语言规范、卷面整洁** | 5% | 书面语，专业术语准确，字迹工整，段落清晰 |

> **提分秘诀**：把教材的核心理论背熟——"原理 + 方法论 + 实际"三者结合的答案最容易拿高分。

下面按照"题目 → 答题框架（是什么/为什么/怎么办）→ 理论依据 → 联系实际示例"的结构，详解 10 道典型论述题。

### 论述题 1：人生观 / 人生价值类

**题目 1**：请结合马克思主义关于人的本质的论述，谈谈你对"人生的真正价值在于对社会的贡献"这一观点的理解，并联系实际说明当代青年应该如何实现自己的人生价值。

#### 答题框架

**（一）是什么：阐释核心概念**
1. 人的本质："在其现实性上，它是一切社会关系的总和"——马克思《关于费尔巴哈的提纲》
2. 人生观三要素：人生目的、人生态度、人生价值
3. 人生价值的两重性：自我价值（个人的满足）和社会价值（对社会的贡献）
4. 亮明观点：人生的真正价值在于对社会的贡献，因为社会价值是自我价值的基础。

**（二）为什么：分三个角度论证**

| 论点 | 理论依据 | 联系实际示例 |
|-----|---------|------------|
| ① 人的社会本质决定了人生价值要从社会维度衡量 | 人的本质属性是社会属性而不是自然属性；人不能脱离社会存在 | 一个离群索居的人（哪怕衣食无忧）很难体现真正的人生价值；而一位山村教师虽工资不高但改变了无数孩子的命运——他的价值通过对社会（学生）的贡献被认可和铭记 |
| ② 社会价值是自我价值实现的前提和基础 | 自我价值和社会价值辩证统一：社会价值是个体自我完善的保障；自我价值的实现是为社会创造更大价值的前提 | 一家企业不为社会创造有价值的产品就无法盈利；同样，个人对社会贡献越大，社会的认可、回报也越多（不是"等价交换"，但总体方向一致） |
| ③ 评价人生价值的根本尺度是社会贡献 | 评价人生价值的根本尺度：看人生活动是否符合社会发展规律、是否促进了历史进步 | 袁隆平一生钻研杂交水稻（社会贡献：解决了亿万人民的吃饭问题），因此他获得共和国勋章、万人敬仰，实现了崇高的人生价值 |

**（三）怎么办：当代青年如何实现人生价值？**
1. **树立正确的人生目的**：把"服务人民、奉献社会"作为自己的人生追求，反对拜金主义、享乐主义、极端个人主义
2. **提升自身素质和能力**：在学习中充实自己、在实践中增长才干，练就过硬本领——"打铁还需自身硬"
3. **投身伟大社会实践**：
   - 把个人理想融入中华民族伟大复兴中国梦
   - 到祖国最需要的地方去：西部计划、三支一扶、基层就业
   - 从小事做起、从本职做起：爱岗敬业，把平凡工作做到出色就是不平凡
4. **正确对待人生顺境与逆境**：顺境不骄傲、逆境不气馁，以积极进取的人生态度奋斗

#### 结尾升华
> 习近平总书记指出："中国梦是历史的、现实的，也是未来的；是我们这一代的，更是青年一代的。"新时代中国青年唯有把小我融入大我，把青春奉献给祖国和人民，才能让自己的人生绽放出绚丽之花，实现真正有价值的人生。

### 论述题 2：理想信念类

**题目 2**：习近平总书记指出："理想信念是共产党人精神上的'钙'，没有理想信念，理想信念不坚定，精神上就会'缺钙'，就会得'软骨病'。"请结合实际谈谈理想信念对大学生成长成才的重要意义。

#### 答题框架

**（一）是什么**
- 理想：人们在实践中形成的、有可能实现的、对未来社会和自身发展的向往与追求
- 信念：人们在一定的认识基础上确立的对某种思想或事物坚信不疑并身体力行的精神状态
- 理想信念是人生的"定向器"和"动力源"；新时代青年应当确立马克思主义的科学信仰，树立中国特色社会主义共同理想和共产主义远大理想

**（二）为什么（三方面意义）**

| 意义 | 理论 | 例子 |
|-----|------|------|
| **指引人生的奋斗目标**（方向） | 理想信念给人生提供方向和目标，没有理想信念人生就像无头苍蝇 | 周恩来少年时"为中华之崛起而读书"——正是崇高理想指引他走上革命道路 |
| **提供人生的前进动力**（动力） | 理想信念是激励人们向着既定目标奋斗前进的力量源泉 | 长征路上红军战士爬雪山过草地，在极端艰苦条件下依然坚持——支撑他们的正是"革命理想高于天"的坚定信念 |
| **提高人生的精神境界**（境界） | 理想信念使人的精神生活各方面统一起来，引导人不断追求更高的人生目标 | 有的人物质富裕但精神空虚（没有理想，人生没有方向感）；有的人物质简朴但精神充实（因为有崇高追求） |

**（三）怎么办：大学生如何确立和践行理想信念？**
1. **确立科学的理想信念**：认真学习马克思主义理论，用理论武装头脑，从思想上真正坚定信仰
2. **立志高远与始于足下相结合**：
   - 立大志：把个人志向和国家前途、民族命运结合起来
   - 始于足下：从现在做起、从小事做起，踏踏实实完成每一步学习和工作
3. **认清实现理想的长期性、艰巨性和曲折性**：
   - 理想的实现是一个过程，不会一蹴而就
   - 正确对待理想与现实的差距：理想很丰满，现实很骨感——但正是因为现实不够完美，才需要我们用奋斗去实现理想
4. **在实践中化理想为现实**：
   - 勇于实践、艰苦奋斗是实现理想的根本途径
   - 积极参加社会实践、志愿服务、专业实习，把书本知识落到实处

#### 结尾升华
> "新时代中国青年要树立远大理想。青年理想远大、信念坚定，是一个国家、一个民族无坚不摧的前进动力。让理想信念在创业奋斗中升华，让青春在创新创造中闪光！"

### 论述题 3：爱国主义 / 中国精神类

**题目 3**：实现中华民族伟大复兴的中国梦，必须弘扬中国精神。请论述什么是中国精神，其核心内涵是什么，以及新时代青年如何弘扬和践行中国精神。

#### 答题框架

**（一）是什么：中国精神的内涵**
```
中国精神 = 以爱国主义为核心的民族精神 + 以改革创新为核心的时代精神
```

- **民族精神（爱国主义为核心）**：伟大创造精神、伟大奋斗精神、伟大团结精神、伟大梦想精神——这是中华民族 5000 年历史长河中积淀的精神基因
- **时代精神（改革创新为核心）**：改革开放以来，特别是新时代，我们在改革创新实践中形成的时代品格（如特区精神、脱贫攻坚精神、抗疫精神等）
- 二者的关系：民族精神是时代精神的根基，时代精神是民族精神在当代的丰富和发展，二者有机统一

**（二）为什么：为什么必须弘扬中国精神？**
1. **中国精神是凝聚中国力量的精神纽带**
   - 14 亿中国人来自五湖四海、各个民族，靠什么凝聚在一起？靠共同的精神信仰和文化认同
   - 抗疫斗争中，举国同心、众志成城——正是中国精神的集中体现
2. **中国精神是激发创新创造的精神动力**
   - 改革创新是时代精神的核心
   - 从"两弹一星"到载人航天、从高铁网络到 5G 技术——中国的科技突破背后都有强大精神动力支撑
3. **中国精神是推进复兴伟业的精神定力**
   - 越是接近民族复兴，道路越不会一帆风顺，越充满风险挑战
   - 必须有坚定的精神定力，走好自己的路，办好自己的事

**（三）怎么办：新时代青年如何弘扬和践行？**
1. **做爱国主义的坚守者和传播者**
   - 把国家和人民的利益放在首位
   - 不做损害国家利益、民族尊严的事
   - 理性爱国：不盲目排外，把爱国热情转化为学习和工作的动力
2. **做改革创新的实践者和生力军**
   - 树立创新意识、培养创新思维
   - 敢于质疑、敢于突破、敢于尝试
   - 积极参加科技创新比赛、科研训练、发明创造
3. **立足本职、脚踏实地**
   - 弘扬中国精神不是空洞口号，要落实到每一天的学习、工作、生活中
   - 勤奋学习、钻研专业 = 用知识报国
   - 艰苦奋斗、敬业奉献 = 用劳动报国

#### 结尾升华
> "人无精神则不立，国无精神则不强。"唯有精神上站得住、站得稳，一个民族才能在历史洪流中屹立不倒、挺立潮头。新时代青年要把中国精神内化于心、外化于行，在实现中国梦的伟大实践中做中国精神的继承者、弘扬者、建设者。

### 论述题 4：社会主义核心价值观类

**题目 4**：社会主义核心价值观包含国家、社会、公民三个层面的内容。请结合实际谈谈大学生应当如何践行社会主义核心价值观。

#### 答题框架

**（一）是什么：核心价值观的基本内容**

| 层面 | 内容（12 个词、24 个字） | 回答什么问题 |
|-----|---------------------|-----------|
| **国家层面**（价值目标） | 富强、民主、文明、和谐 | 我们要建设什么样的国家？ |
| **社会层面**（价值取向） | 自由、平等、公正、法治 | 我们要建设什么样的社会？ |
| **公民层面**（价值准则） | 爱国、敬业、诚信、友善 | 我们要培育什么样的公民？ |

- 社会主义核心价值观是当代中国精神的集中体现，凝结着全体人民共同的价值追求

**（二）为什么：为什么要践行核心价值观？（为什么重要）**
1. 是实现中华民族伟大复兴的价值支撑——价值观统一，人民才有凝聚力
2. 是当代青年成长成才的"价值定盘星"——面对纷繁复杂的社会思潮（拜金、躺平、精致利己等），核心价值观给我们提供正确的价值判断标准
3. 是抵御西方意识形态渗透的文化防线——价值观之争是没有硝烟的战争

**（三）怎么办：大学生如何践行？（8 个词逐一对应做法）**

重点是**公民个人层面的四个词**（爱国、敬业、诚信、友善），这是大学生最直接能做到的：

| 核心价值词 | 大学生如何践行（具体做法） |
|----------|------------------------|
| **爱国** | ① 升国旗奏国歌时肃立致敬；② 主动学习党史国史，增强国家认同感；③ 不说损害国家荣誉的话，不做损害国家利益的事；④ 把个人发展融入国家发展 |
| **敬业** | 学生的"业"就是**学业**——① 认真上好每一堂课、完成每一份作业；② 不逃课、不作弊；③ 刻苦钻研专业，练就扎实本领；④ 培养职业精神和责任意识 |
| **诚信** | ① 诚信考试（不作弊）；② 诚信做人（不撒谎、不造假、不剽窃论文）；③ 按时偿还助学贷款、信守承诺；④ 知行合一，说到做到 |
| **友善** | ① 尊敬师长、团结同学；② 乐于助人（学业上互助、生活中关心同学）；③ 参加志愿服务和公益活动；④ 尊重他人、理性沟通、文明上网 |

再结合国家和社会层面：
- 大学生是未来的建设者，要深刻理解"富强民主文明和谐"的国家目标，为之奋斗
- 在日常生活中维护"自由平等公正法治"：从身边小事做起，遵法守法，平等待人

#### 结尾升华
> "道不可坐论，德不能空谈。"践行社会主义核心价值观，不能停留在背诵 24 个字上，而要落实到每一次选择、每一个行动中。于实处用力，从知行合一上下功夫，核心价值观才能内化为人们的精神追求，外化为人们的自觉行动。

### 论述题 5：道德 / 明大德守公德严私德类

**题目 5**：习近平总书记强调，要"明大德、守公德、严私德"。请结合实际谈谈新时代大学生应当如何加强道德修养。

#### 答题框架

**（一）是什么：三德的内涵**

| 道德层次 | 内涵 | 针对对象 |
|---------|------|---------|
| **明大德** | 坚定理想信念，涵养高尚的政治品德和家国情怀 | 国家层面：对党忠诚、报效国家、服务人民 |
| **守公德** | 遵守公共道德，维护社会公共秩序，关爱他人、服务社会 | 社会层面：文明礼貌、助人为乐、爱护公物、保护环境、遵纪守法 |
| **严私德** | 严格约束自己的操守和行为，谨言慎行、慎独慎微 | 个人层面：品行端正、作风正派、廉洁自律、尊老爱幼、家风建设 |

> 三者关系：大德是方向，公德是底线，私德是基础，三位一体、互相促进。

**（二）为什么：为什么要加强道德修养？**
1. 道德是做人的根本——"才者，德之资也；德者，才之师也"（司马光）——有才无德，其才足以济其奸
2. 是大学生成长成才的内在要求——先成人，后成才；道德品质是人才评价的第一标准
3. 是净化社会风气的需要——大学生是社会先进青年群体，大学生的道德风貌引领社会风气

**（三）怎么办：大学生如何加强道德修养？（重点答三德）**

**1. 明大德：铸牢理想信念之魂**
- 坚定马克思主义信仰、共产主义远大理想和中国特色社会主义共同理想
- 爱国爱党爱社会主义，把个人理想融入民族复兴伟业
- 面对大是大非敢于亮剑，面对歪风邪气敢于斗争

**2. 守公德：做文明有礼的时代新人**

  - ❌ 帮信罪：不要把银行卡、电话卡借给别人（可能被用于电信诈骗洗钱，借卡人也构成犯罪）

- 自觉履行法律义务：依法纳税、依法服兵役、遵守交通法规等

  - 兼职欠薪 → 向劳动监察部门投诉
  - 校园欺凌 / 名誉侵权 → 保留证据，向学校报告，必要时报警 / 起诉
- 敢于同违法犯罪行为作斗争：注意方式方法，量力而行，先保护自己（拨打 110 报警等），做社会主义法治的坚定捍卫者

#### 结尾升华

### 论述题 8：辩证思维 / 矛盾分析类（马原）

**题目 8**：近年来，互联网、人工智能、大数据等新技术飞速发展，深刻改变了人们的生产生活方式。有人认为科技发展带来了巨大便利，也有人担忧科技会带来失业、隐私泄露、伦理问题等负面影响。请运用**唯物辩证法的矛盾原理**谈谈你对科技发展影响的看法。

#### 答题框架

**（一）是什么：亮明观点 + 阐释原理**

**核心观点**：要用**一分为二、全面辩证**的观点看待科技发展，既要看到它的积极作用（主流），也要正视它带来的问题（支流），同时不能因噎废食——矛盾双方在一定条件下可以相互转化，关键是我们如何引导。

**原理阐释**：唯物辩证法的矛盾原理（对立统一规律）告诉我们：
1. **矛盾具有普遍性**：事事有矛盾、时时有矛盾，任何事物都包含着既对立又统一的两个方面
2. **矛盾具有特殊性**：不同事物的矛盾各有特点，要具体问题具体分析
3. **矛盾发展具有不平衡性**：要分清**主要矛盾和次要矛盾**、**矛盾的主要方面和次要方面**（"两点论"和"重点论"的统一）——事物的性质主要是由主要矛盾的主要方面决定的

**（二）为什么：运用原理分层次分析**

**1. 矛盾普遍性：科技发展的"双刃剑"效应（一分为二）**

| 正面影响（利） | 反面问题（弊） |
|--------------|--------------|
| 生产力飞跃：生产效率极大提高，物质财富增加 | 结构性失业：部分传统岗位被机器替代（如流水线工人、出纳） |
| 生活便利：移动支付、外卖、导航、远程教育医疗 | 隐私泄露：大数据采集个人信息，存在数据安全和滥用问题 |
| 医疗进步：基因测序、靶向药、疫苗研发加速 | 伦理风险：基因编辑、人工智能武器、深度伪造技术 |
| 信息平等：互联网降低知识门槛，缩小数字鸿沟（同时也可能加大） | 信息茧房 / 算法推荐：人被算法"喂养"，观点极化 |

**2. 矛盾不平衡性：要分清主流和支流（两点论 + 重点论）**
- **主流（矛盾主要方面）是积极的**：科技发展推动社会进步、促进人的全面发展是主要方面——人类历史上每一次科技革命都带来了社会文明的大跨步
- **支流（次要方面）是问题**：负面影响确实存在，但比起科技带来的进步是第二位的
- **不能因噎废食**：不能因为有负面问题就否定科技、反对科技进步——因为问题不是科技本身的问题，而是**人如何运用科技、如何治理科技**的问题
  - 例：有了汽车就有了交通事故，但不能因此不造汽车——而是要制定交通规则、考驾照、修红绿灯 → 用法律和制度规范科技的使用

**3. 矛盾同一性：矛盾双方相互贯通，在一定条件下相互转化**
- 矛盾的双方（利与弊）不是绝对对立的，在一定条件下可以相互转化：
  - 例 1：AI 替代一些传统岗位（弊）→ 但同时创造了 AI 训练师、算法工程师等新岗位（利）→ 关键是帮助劳动者实现技能升级转型
  - 例 2：大数据带来隐私风险（弊）→ 但也催生了数据安全、隐私计算等新领域的发展（利）→ 关键是完善法律监管（如《个人信息保护法》）

**（三）怎么办：如何正确应对科技发展的双刃剑效应？**

1. **国家层面：完善法律和制度规范**
   - 立法先行：完善《个人信息保护法》《数据安全法》《生成式人工智能服务管理暂行办法》等法律法规，给科技发展划出"红线"
   - 建立科技伦理审查制度：基因编辑、医疗人工智能等高风险领域的技术应用，先过伦理关
2. **社会层面：加强科技伦理教育和科普**
   - 公众提高科技素养，理性看待科技
   - 媒体正确引导，不炒作"科技恐惧症"也不盲目"科技万能论"
3. **个人层面：理性拥抱科技 + 提升自身能力**
   - 做科技的主人，不做科技的奴隶：合理使用手机/网络，拒绝沉迷，保持独立思考
   - 适应科技变革：**终身学习**——未来可能不是"机器取代人"，而是"会用 AI 的人取代不会用 AI 的人"

#### 结尾升华
> 科技是中性的，它带来什么结果，最终取决于使用它的人。站在新一轮科技革命和产业变革的十字路口，我们既要保持对科技的热情和信心（抓主流），又要保持清醒和审慎（防风险），以辩证思维驾驭科技之舟，让科技真正服务人类、造福社会——这正是马克思主义唯物辩证法教给我们的智慧。

### 论述题 10：历史 / 党史类

**题目 10**：2021 年 7 月 1 日是中国共产党成立 100 周年。一百年来，中国共产党团结带领中国人民取得了革命、建设、改革的伟大胜利。请结合历史和现实，论述"中国共产党为什么能、马克思主义为什么行、中国特色社会主义为什么好"。

#### 答题框架（精简版）

**（一）是什么**
"中国共产党为什么能、马克思主义为什么行、中国特色社会主义为什么好"（简称"三个为什么"）是理解中国近现代历史的一把"金钥匙"，三者有机统一：
- 中国共产党"能"是关键
- 马克思主义"行"是根本
- 中国特色社会主义"好"是结果

**（二）为什么（逐一展开，"历史 + 现实"论证）**

**1. 中国共产党为什么能？**
| 原因 | 历史实例 |
|-----|---------|
| ① 有科学理论指导（马克思主义中国化时代化） | 毛泽东思想指引革命胜利 → 邓小平理论指引改革开放 → 习近平新时代中国特色社会主义思想指引新时代 |
| ② 有坚定的理想信念 | "革命理想高于天"，从建党时 50 多名党员到今天 9800 多万党员的百年大党，历经磨难而不衰 |
| ③ 有人民至上的根本立场 | "全心全意为人民服务"是党的根本宗旨；脱贫攻坚战不惜一切代价保护人民生命财产 |
| ④ 有自我革命的勇气 | 敢于刀刃向内：延安整风、十一届三中全会拨乱反正、全面从严治党反腐败 |

**2. 马克思主义为什么行？**
- **因为它是科学的**：揭示了自然界、人类社会、人类思维发展的普遍规律
- **因为它是人民的**：第一次创立了人民实现自身解放的思想体系（不是为少数剥削阶级服务的）
- **因为它是实践的**：马克思主义不是教条，而是行动指南；在中国的成功就在于"马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合"（"两个结合"）
- **因为它是发展的**：不断与时俱进——列宁主义→毛泽东思想→中国特色社会主义理论体系→习近平新时代中国特色社会主义思想

**3. 中国特色社会主义为什么好？**
- **好在它创造了世所罕见的两大奇迹**：经济快速发展奇迹 + 社会长期稳定奇迹（这是西方理论无法解释的）
- **好在它以人民为中心**：共同富裕、人民当家作主
- **好在它集中力量办大事的制度优势**：脱贫攻坚、疫情防控、载人航天、北斗导航——都是举国体制集中力量办大事的成果
- **实践是检验真理的唯一标准**：
  - 横向比：同样起步条件的国家中，中国发展最好、最稳
  - 纵向比：新中国成立七十多年，走完了发达国家几百年走过的工业化历程

**（三）怎么办：青年如何以史为鉴、开创未来？**
1. **学史明理、学史增信、学史崇德、学史力行**——从百年党史中汲取智慧和力量
2. **始终坚持党的领导，听党话、跟党走**——这是中国人民从长期奋斗中得出的最基本结论
3. **坚定"四个自信"，做新时代奋斗者**
4. **把个人理想融入党和人民事业**：到党和人民需要的地方去建功立业

#### 结尾升华
> "初心易得，始终难守。以史为鉴，可以知兴替。"我们要用历史映照现实、远观未来，从中国共产党的百年奋斗中看清楚过去我们为什么能够成功、弄明白未来我们怎样才能继续成功，从而在新的征程上更加坚定、更加自觉地牢记初心使命、开创美好未来。

## 第三章 答题避坑指南

### 3.1 论述题常见失分点（千万不要犯！）

| 错误类型 | 典型表现 | 后果 | 怎么避免 |
|---------|---------|------|---------|
| **政治方向错误** | 出现否定党的领导、否定社会主义、美化西方的言论 | 直接 0 分，严重的可能处理 | 这是**绝对红线**，答题时立场必须坚定正确，任何怀疑、模糊都不行 |
| **通篇没有理论** | 全篇都是个人感想，像写散文、写作文，一个教材原理都没有用 | 得分很低，甚至不及格 | 一定要有意识地使用课本上学过的**理论、原理、概念、名言**，这是考查的重点 |
| **结构不完整，只有一段** | 整个答案就写一大段，没有分点，层次不清 | 老师找不到得分点，印象分就低了 | 一定要分段落（是什么/为什么/怎么办），每段有中心句；条件允许的话用"①②③"分论点 |
| **只有理论，没有实际** | 理论背得很熟，但没有任何例子、数据、联系实际 | 显得空洞，不能体现能力 | 每个论点至少配一个**联系实际**的例子（最好是近年的、有时代感的例子） |
| **审题不清，答非所问** | 题目问"怎么做"，通篇答"是什么为什么"；题目要"结合矛盾原理"，没有用原理，空谈感想 | 严重跑题，分数很低 | 作答前一定**花 2~3 分钟审题**，圈出关键词：什么原理？什么主题？几问？ |
| **字迹潦草，难以辨认** | 字龙飞凤舞，涂改严重 | 老师改卷时看不清楚，不会仔细找得分点 | 不用写得很美观，但一定要**工整、清楚**，卷面整洁 |
| **字数严重不足** | 题目要求 800 字，只写 200 字 | 内容肯定不完整，得分不可能高 | 按总分/字数比例写；一般 1 分 = 30~50 字，20 分题写 600~1000 字左右 |

### 3.2 论述题答题时间分配建议

以一场 2 小时（120 分钟）的思政课期末考试为例：

| 题型 | 答题时间建议 | 说明 |
|-----|-----------|------|
| 选择题/判断题 | 15~20 分钟 | 快速完成，不纠结，不会的先标 |
| 简答题 | 25~30 分钟 | 每题 5~7 分钟，"问什么答什么"，不要展开太啰嗦 |
| **论述题**（2~3 道） | 50~60 分钟（每题 20~30 分钟） | 一定要留足时间！这是分值最大的题，也是最能拉分的题 |
| 检查 | 10 分钟 | 检查姓名学号、有没有漏题、简单复查选择题涂卡 |

> 在动笔写论述题之前，建议先用 2 分钟在草稿纸上写一个简单的答题提纲（是什么 3 个要点、为什么 3 个论点、怎么办 3 条做法），避免写到一半逻辑混乱或者写漏点。

### 3.3 好用的"万能"开头结尾句

适当背一些经典表述，有助于在考场上快速下笔：

**开头句**：
- "新时代以来，在以习近平同志为核心的党中央坚强领导下，中国特色社会主义事业取得了历史性成就……"
- "马克思主义认为，……（点明相关原理）。这一科学论断为我们认识和分析……问题提供了锐利的思想武器。"
- "……问题，不仅是一个重要的理论问题，也是一个重大的现实问题，关系到……的大局，必须正确认识和对待。"

**结尾句**：
- "站在'两个一百年'奋斗目标的历史交汇点上……"
- "新时代中国青年要以实现中华民族伟大复兴为己任，增强做中国人的志气、骨气、底气，不负时代，不负韶华，不负党和人民的殷切期望！"
- "道阻且长，行则将至；行而不辍，未来可期。只要我们……，就一定能……"
- "让我们更加紧密地团结在以习近平同志为核心的党中央周围，埋头苦干、勇毅前行，为全面建设社会主义现代化国家、全面推进中华民族伟大复兴而团结奋斗！"
