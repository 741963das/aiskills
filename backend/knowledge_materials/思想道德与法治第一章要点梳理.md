# 思想道德与法治 第一章 要点梳理

## 第一章 人生的青春之问（人生观部分）

> **课程定位**：本章是"思想道德与法治"课程的开篇之章，核心回答"**人为什么活着？怎样活着才有价值？**"这一人生根本问题。学好本章是理解后续爱国主义、道德观、法治观的前提。

---

## 第一节 人生观是对人生的总看法

### 1.1 世界观与人生观

#### 一、什么是世界观？

**世界观**是人们对**整个世界**（包括自然界、人类社会和人的精神世界）的**总的看法和根本观点**。

例如：
- 物质和意识谁是第一性？→ 唯物主义 vs 唯心主义
- 世界是静止不变的还是运动发展的？→ 形而上学 vs 辩证法
- 人类社会发展有没有规律？规律能否被认识？→ 历史唯物主义 vs 历史唯心主义

#### 二、什么是人生观？

**人生观**是人们在实践中形成的对**人生目的和意义**的根本看法。它回答三个核心问题：

| 人生观三大问题 | 含义 |
|--------------|------|
| **人生目的** | 人为什么活着？（人活着要追求什么？） |
| **人生态度** | 人应当怎样活着？（面对人生境遇的心态） |
| **人生价值** | 怎样的人生才有价值？（什么样的人生是有意义的？） |

> **记忆口诀**："目的"是为什么活着（方向），"态度"是怎么活着（状态），"价值"是活得有没有意义（评价）。

#### 三、世界观与人生观的辩证关系

这是重要的考点（选择题、辨析题常考）：

```
┌─────────────────────────────────────────────┐
│  世界观决定人生观（★ 更根本的是世界观）          │
│  · 有什么样的世界观，就有什么样的人生观         │
│  · 世界观是人生观的理论基础                    │
├─────────────────────────────────────────────┤
│  人生观反作用于世界观                         │
│  · 人生观的变化会促使人们重新审视和思考世界    │
│  · 积极的人生观有助于人们确立正确的世界观      │
└─────────────────────────────────────────────┘
```

**辨析题示例**：
> "人生观决定世界观。"
> 答：这个说法是**错误的**。正确关系是世界观决定人生观，世界观是更根本的；人生观对世界观具有反作用，二者相互联系、相互影响。题目将二者关系颠倒了。

### 1.2 人生观的核心——人生目的

在人生观三个内容中，**人生目的是核心**，居于主导地位。

为什么人生目的是核心？因为：
1. **人生目的决定人生道路**——方向对了，路才不会走偏
2. **人生目的决定人生态度**——有了目标，才会有积极进取的人生态度
3. **人生目的决定人生价值选择**——目的决定了你认为什么是有价值的

> 可以这样理解：人生目的是"方向盘"，人生态度是"发动机的转速"，人生价值是"行驶的社会贡献"。方向盘决定了整个方向。

### 1.3 人的本质——一切社会关系的总和

这是马克思主义对人的本质的科学论断（常考）：

> **马克思在《关于费尔巴哈的提纲》中指出**：
> "人的本质不是单个人所固有的抽象物，在其现实性上，它是**一切社会关系的总和**。"

这句话的深刻含义：

| 层面 | 含义 |
|-----|------|
| **不是"抽象的"人** | 人的本质不是单个人天生就有的、永恒不变的人性（如"人性本善/恶"等抽象议论） |
| **是"社会关系"** | 人的本质是由人所处的各种社会关系（经济关系、政治关系、家庭关系、思想关系等）决定的 |
| **是"总和"** | 不是某一种社会关系单方面决定，而是所有社会关系综合作用的结果 |
| **是"现实的"** | 要具体地、历史地看人的本质——不同时代、不同社会、不同阶级的人有不同的本质 |

**重要推论**：
- 人具有**自然属性**（生物本能，如吃饭、睡觉、繁衍）和**社会属性**（处于社会关系中）
- **人的社会属性才是人的本质属性**，它把人和动物从根本上区别开来
- "狼孩"虽然有人的自然形体，但脱离了人类社会，就不具备人的本质特征

## 第二节 个人与社会的辩证关系

### 2.1 个人与社会是对立统一的关系

这是人生观的基本问题。不能割裂个人与社会的关系。

```
个人与社会的关系：

  ┌──────────────┐    相互依存    ┌──────────────┐
  │    个人      │ ←──────────→ │    社会       │
  └──────────────┘                └──────────────┘
        ↑                               ↑
        │ 个人是社会的细胞              │ 社会是个人生存发展的前提
        │ 每个人都生活在社会中           │ 没有个人就没有社会
        │ 不能脱离社会而存在             │ 社会由无数个人构成
```

#### 二者的统一性（相互依存、相互制约）

| 社会对个人的作用 | 个人对社会的作用 |
|---------------|---------------|
| 社会是个人生存和发展的**前提条件**（没有社会提供的物质文化条件，个人无法生存发展） | 个人是社会的**细胞和主体**（社会由个人组成，没有人就没有社会） |
| 社会的发展水平决定了每个人自由发展的程度 | 个人能力的发挥、个人的劳动和创造推动社会进步 |
| 社会的道德、法律、制度规范和约束个人行为 | 良好的个人素质和道德水平促进社会和谐 |

#### 二者的对立性（存在矛盾）

- 个人利益和社会整体利益之间有时会发生冲突
- 个人自由与社会约束之间的矛盾
- 个人理想与社会需要之间的矛盾

**如何正确处理矛盾**？
- 个人利益**服从**社会整体利益
- 在保证社会整体利益的前提下，维护个人正当利益
- 反对两种极端错误：
  1. **极端个人主义**：片面强调个人利益，牺牲社会利益（错误）
  2. **完全抹杀个人利益**：只讲社会利益不讲个人利益（也是片面的）

### 2.2 正确认识个人理想与社会理想的关系

| 关系 | 说明 |
|-----|------|
| **社会理想规定、指引个人理想** | 个人理想的实现以社会理想的实现为前提，不能脱离时代空谈个人理想 |
| **个人理想体现社会理想** | 社会理想不是凭空的，它要靠无数个人的个人理想来实现 |
| **两者统一于社会实践** | 在实现中华民族伟大复兴中国梦（社会理想）的过程中实现每个人的人生理想（个人理想） |

> **经典论述**：
> "新时代中国青年要把自己的小我融入祖国的大我、人民的大我之中，与时代同步伐、与人民共命运，才能更好实现人生价值、升华人生境界。"
> ——习近平

## 第三节 人生目的——人为什么活着

### 3.1 人生目的的层次划分

现实中，人们的人生目的多种多样，大致可以分为不同层次：

| 层次（由低到高） | 人生目的类型 | 典型想法 | 评价 |
|---------------|-----------|---------|------|
| 最低层次 | 个人主义 / 拜金主义 / 享乐主义 | "人生苦短，及时行乐""人不为己天诛地灭""有钱就是成功" | 错误的人生观，把个人利益、物质享受置于一切之上 |
| 中间层次 | 个人家庭幸福型 | "努力工作，养家糊口，让家人过上好日子" | 合理的、正当的，但还有更高层次的追求 |
| 高尚层次 | 服务人民、奉献社会 | "把有限的生命投入到无限的为人民服务之中""为中华民族伟大复兴而奋斗" | 科学高尚的人生观，与社会利益高度统一 |

### 3.2 反对错误的人生观（辨析题、论述题考点）

#### （一）反对拜金主义

**什么是拜金主义**：把金钱视为人生最高目的，一切向钱看，金钱是衡量一切的标准。

**错误本质**：
- 颠倒了人和物的关系——本来人创造了金钱，却反过来被金钱支配，成了"金钱的奴隶"
- 混淆了"手段"和"目的"——金钱是生活的手段（可以买东西），不是人生的目的（不能买亲情、健康、尊严）

#### （二）反对享乐主义

**什么是享乐主义**：把感官的快乐、物质享受作为人生唯一追求，"人生在世，吃喝二字"。

**错误本质**：
- 把人的自然属性（吃喝本能）当作人的本质，忘记了人还有社会属性和精神追求
- 享乐主义到极致就是挥霍浪费、骄奢淫逸，既损害个人健康也败坏社会风气
- 享乐主义的后果：玩物丧志，人变成了欲望的奴隶

#### （三）反对极端个人主义

**什么是极端个人主义**：个人利益至上，把个人利益放在集体、社会利益之上，为了个人利益不惜损害他人和社会利益。

**错误本质**：
- 割裂了个人与社会的辩证统一关系，只强调个人不讲社会
- 极端个人主义发展下去：损人利己、损公肥私、违法犯罪

> **三个"主义"的共同错误根源**：
> 它们的共同本质都是**剥削阶级的人生观**，出发点和落脚点都是"一己私利"，没有正确认识个人与社会的辩证关系，把个人利益凌驾于社会利益之上。

### 3.3 科学高尚的人生追求：服务人民、奉献社会

为什么说"服务人民、奉献社会"是科学高尚的？

1. **它正确反映了人的社会本质**——人是社会的人，人生的意义在于对社会做出贡献
2. **它实现了个人与社会的真正统一**——在奉献社会中实现个人价值，而不是对立
3. **它经得起历史和实践检验**——雷锋、焦裕禄、黄大年、张桂梅……一代代先进人物用实际行动证明了这种人生的崇高和充实

**毛泽东同志对"为人民服务"的经典论述**：
> "人固有一死，或重于泰山，或轻于鸿毛。为人民利益而死，就比泰山还重；替法西斯卖力，替剥削人民和压迫人民的人去死，就比鸿毛还轻。"
> ——毛泽东《为人民服务》（1944年纪念张思德）

## 第四节 人生态度——怎样对待人生

### 4.1 什么是人生态度？

人生态度是指人们通过生活实践形成的对人生问题的一种**稳定的心理倾向和基本意图**。

简单说：人活着，应该以什么样的**心态和精神面貌**去面对人生中的成功与失败、顺境与逆境。

### 4.2 四种典型的人生态度

| 人生态度 | 特点 | 评价 |
|---------|------|------|
| **积极进取的人生态度** | 正视现实、热爱生活、对未来充满希望；胜不骄败不馁 | ✅ 正确的、应提倡的 |
| **消极无为的人生态度** | "躺平""佛系""看破红尘""差不多就行"，缺乏斗志 | ❌ 错误的，浪费青春 |
| **悲观厌世的人生态度** | 觉得人生没有意义，对一切失望，甚至轻视生命 | ❌ 极端错误，非常危险 |
| **投机侥幸的人生态度** | 幻想"一夜暴富""走捷径"，不愿踏实奋斗 | ❌ 错误，往往误入歧途 |

### 4.3 正确人生态度的四个关键词

**1. 认真**
- 严肃认真地对待人生的每一件事，不敷衍、不糊弄
- 对自己负责：对健康、学业、工作、家庭认真
- 对他人负责：诚实守信、信守承诺

**2. 务实**
- 一切从实际出发，不好高骛远
- "不积跬步无以至千里"——从小事做起，从当下做起
- 不幻想天上掉馅饼，脚踏实地一步一个脚印

**3. 乐观**
- 相信前途是光明的，道路是曲折的
- 面对困难挫折不气馁，办法总比困难多
- 乐观不是盲目乐观，而是认清困难后仍然满怀信心前行

**4. 进取**
- 人生如逆水行舟，不进则退
- 始终保持学习热情和奋斗精神
- "苟日新，日日新，又日新"——不断超越自我

### 4.4 正确看待人生的顺境与逆境

| 境遇 | 特点 | 如何正确对待 |
|-----|------|------------|
| **顺境** | 人生道路一帆风顺，各方面条件好 | 不骄傲自满、不挥霍浪费；顺势而为，抓住机遇加速成长，同时居安思危 |
| **逆境** | 遇到困难挫折、压力打击 | 不气馁消沉；磨炼意志、增长才干；逆境是试金石，熬过去就更强大 |

**经典名言**：
- "宝剑锋从磨砺出，梅花香自苦寒来。"
- "天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为，所以动心忍性，曾益其所不能。"——《孟子》
- "逆境是达到真理的一条通路。"——拜伦

## 第五节 人生价值——什么样的人生才有意义

### 5.1 人生价值的两重性

人生价值内在地包含了两个方面：**自我价值**和**社会价值**。

| 维度 | 自我价值（个体性） | 社会价值（社会性） |
|-----|-----------------|-----------------|
| **定义** | 个体的人生活动对自己生存和发展所具有的价值，主要表现为对自身物质和精神需要的满足程度 | 个体的人生活动对社会、他人所具有的价值，主要表现为对社会所做的贡献 |
| **评价角度** | "我得到了什么？""我活得好不好？" | "我为社会、他人付出了什么？做出了什么贡献？" |
| **具体表现** | 衣食住行条件、教育水平、健康状况、尊严幸福感等 | 劳动创造、公益奉献、为社会提供产品服务、为他人提供帮助等 |

### 5.2 自我价值与社会价值的辩证关系

二者**既相互区别，又密切联系、相互依存，共同构成人生价值的矛盾统一体**：

```
┌──────────────────────────────────────────────────────────┐
│  第一方面：社会价值的实现是个体自我完善、全面发展的保障       │
│  · 没有社会价值（不对社会做贡献），自我价值也难以真正实现    │
│  · 例如：一个企业不为社会创造有价值的产品/服务，就无法盈利   │
│        → 员工的工资福利（自我价值）就无从谈起              │
├──────────────────────────────────────────────────────────┤
│  第二方面：人的自我价值的实现是个体为社会创造更大价值的前提   │
│  · 个人有了基本的物质生活保障和尊严感（自我价值实现）       │
│    才能更有条件地去奉献社会、创造社会价值                   │
│  · 无法想象一个食不果腹、没有尊严的人还能全心全意贡献社会    │
└──────────────────────────────────────────────────────────┘
```

**结论（非常重要！）**：

> **人生的真正价值在于对社会的贡献（社会价值）。**
> 
> 因为：
> 1. 社会价值是社会存在和发展的要求——没有每个成员的贡献，社会就无法存在和进步
> 2. 社会价值是自我价值的基础——一个人对社会贡献越大，社会给予他的认可和回报也越多
> 3. 从评价角度看：一个人的人生价值大小，主要不在于他从社会"取得"了多少，而在于他"贡献"了多少

### 5.3 人生价值的评价标准和方法

#### 一、评价标准

根本尺度：**看一个人的人生活动是否符合社会发展的客观规律，是否通过实践促进了历史的进步**。

在今天的社会主义中国，具体标准就是：
- 是否以自己的劳动和聪明才智为**中国特色社会主义事业**真诚奉献
- 是否为**人民群众**尽心尽力服务

#### 二、评价方法（四个"坚持"）

| 方法 | 含义 | 为什么要这样做 |
|-----|------|-------------|
| **坚持能力大小与贡献尽力相统一** | 每个人能力有大小，但只要尽自己最大努力去奉献，就是有价值的 | 不能只看科学家、企业家才有价值；普通劳动者踏实工作、奉献一生同样有价值 |
| **坚持物质贡献与精神贡献相统一** | 既要看到对社会物质财富的贡献，也要看到对精神文明、思想道德的贡献 | 老师教书育人、医生救死扶伤、道德模范感召社会，这些精神贡献有时比物质贡献更深远 |
| **坚持完善自身与贡献社会相统一** | 个人素质的提高（完善自身）和奉献社会是相辅相成的 | "打铁还需自身硬"，提升自己的能力才能做出更大贡献 |
| **坚持动机与效果相统一** | 既要看出发点（动机是不是好的），也要看实际结果（效果是不是好的） | "好心办坏事"要反思方法，"坏心办好事"本质还是不对；动机和效果要统一评价 |

### 5.4 人生价值的实现条件

| 条件分类 | 具体内容 |
|---------|---------|
| **从社会客观条件出发** | 要符合社会发展规律、适应国家和时代的需要；利用好社会提供的客观条件（教育、平台、政策等） |
| **从个体自身条件出发** | 正确认识自己，发挥自身优势，弥补不足；不断提升自己的能力和素质 |
| **不断增强实现人生价值的能力和本领** | 核心是**奋斗和实践**：<br>1. 在学习中充实自己<br>2. 在实践中增长才干<br>3. 在创新创造中贡献社会 |

   → 答案：B（《关于费尔巴哈的提纲》中的经典论断）

3. 科学高尚的人生观的核心内容是（    ）
   A. 金钱至上  B. 及时享乐  C. 服务人民、奉献社会  D. 个人利益优先
   → 答案：C

### 二、辨析题考点自查

判断正误并说明理由：

1. "世界观和人生观是彼此独立的，互不影响。"
   → 错误。世界观决定人生观，人生观反作用于世界观，二者辩证统一，紧密联系。

2. "评价一个人的人生价值，主要看他赚了多少钱，获得了多高的社会地位。"
   → 错误。人生价值评价的根本尺度是看其是否符合社会发展规律、是否对社会进步做出贡献。人生的真正价值在于对社会的贡献（社会价值），而不是以个人财富和地位作为评价标准。

3. "顺境有利于人的成长，逆境不利于人的成长。"
   → 片面。顺境为人的成长提供有利条件，但也容易使人骄傲自满；逆境虽然困难，但能磨炼意志、增长才干。只要正确对待，无论顺境逆境都可以成为人生的财富。
